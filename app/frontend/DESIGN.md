# Mobile Dashboard Design

Preserve MatchMe's existing blue/slate palette, Poppins headings, Open Sans body and Sparkles logo. Mobile only: physical left compact logo/right accessible search, safe-area header, restrained two-column quick-access buttons, five compact application rows, text-and-color status badges. Dedicated search and category/details views remain within Dashboard, preserving overview scroll/filter state and existing three-tab navigation. Use 44px controls, wrapping text and RTL logical spacing. No marketing imagery, charts, gradients or decorative statistics.

Desktop retains the current Dashboard component/layout, with shared canonical status labels only.
