# MATCHME — MOBILE JOB SEEKER PROFILE REDESIGN
## Account Overview | Support Center | Subscription | VIA Resume | Personal Information

### OBJECTIVE

Redesign the existing MatchMe Job Seeker Profile tab for the **mobile application only**.

The Profile page should become a professional, premium-looking account overview with clearly organized information and functional navigation.

The design must feel like a polished recruitment application, not a generic AI-generated dashboard.

Preserve all existing functionality, Supabase records, authentication, subscriptions, credits, resume uploads, and Job Seeker data.

Do not rebuild the Profile system or introduce duplicate databases.

The application remains named **MatchMe**. The premium subscription and resume feature retain the VIA branding.

All Atoms development communication and final reports must be in English only. Preserve English and Arabic application localization.

---

# PART 1 — MOBILE PROFILE MAIN PAGE

## 1. Header

At the very top of the Profile page, create a compact header.

**Top-left:**
- Official MatchMe application logo.
- Preserve its existing proportions.
- Use the same logo size and positioning as the mobile Swipe and Dashboard pages.

**Top-right:**
- A clickable information icon represented by a lowercase **i** inside a circle.
- Use a professional, minimal icon.
- The icon must open the Support & Settings page.

The header must remain visually consistent with the other mobile tabs.

## 2. Job Seeker Account Overview

Immediately below the header, display the following account information in this order:

**Username**
- Display the Job Seeker's actual username or existing display name.
- Do not invent a username if the account has none.
- Use the canonical profile field.

**Email Address**
- Display the user's registered email address.
- Retrieve it from the existing authenticated account.

**Mobile Number**
- Display the saved mobile number with its international country code.
- Format the number appropriately.
- If no mobile number exists, display "Not added" rather than fabricated information.

**Attached CV**
- Display the filename of the Job Seeker's currently attached CV.
- Display the date it was last updated.
- Example: "Last updated: 20 October 2026".
- Use the actual stored file metadata.
- Make the CV row clickable to open a preview or existing authorized download action.
- If no CV is attached, display "No CV uploaded".
- Provide a clear way to add or replace the CV using the existing resume upload functionality.

Do not confuse the uploaded CV with the generated VIA Resume.

The uploaded CV is the original document provided by the user.

The VIA Resume is a separate generated ATS-friendly document created from the user's structured MatchMe profile.

## 3. Visual Structure

Use a clean, compact information block.

Suggested hierarchy:

MatchMe Logo                         (i)

Username

Email address

Mobile number

Attached CV
Filename
Last updated: Date

Avoid large decorative cards, unnecessary dividers, oversized avatars, and excessive scrolling.

Use clear typography and comfortable spacing.

# PART 4 — VIA RESUME

## 6. VIA Resume Button

Below Subscription Overview, display:

**VIA Resume**

Use a professional document or resume icon.

When tapped, open the VIA Resume page.

## 7. VIA Resume Purpose

VIA Resume allows a Job Seeker to generate and download an ATS-friendly resume as a PDF using the information already saved in their MatchMe profile.

The user should not need to manually re-enter information already stored in MatchMe.

Use the existing structured Job Seeker profile as the authoritative data source.

## 8. Resume Content

Generate the resume using available information from:

- Legal first and family name.
- Email address.
- Mobile number.
- Current city and country.
- Professional experience.
- Education.
- Skills.
- Certifications.
- Languages.

Include relevant professional information already available in the profile.

Do not automatically include birthday, gender, or other sensitive personal information in the ATS resume.

Do not invent work experience, qualifications, dates, achievements, or certifications.

Do not fabricate a professional summary.

If information is missing, omit optional resume sections or identify missing essential information before generating.

## 9. ATS-Friendly PDF Design

The generated resume must:

- Be professionally formatted.
- Use a clean, single-column layout.
- Have selectable and searchable text.
- Use standard section headings.
- Avoid tables for critical resume content.
- Avoid graphics, icons, and complex columns that could interfere with ATS parsing.
- Use consistent fonts and spacing.
- Display experience from most recent to oldest.
- Display education from most recent to oldest.
- Display certifications from most recent to oldest.
- Use the existing canonical date formatting rules.
- Support English and Arabic text correctly.

The resume should be suitable for uploading to recruitment platforms and applicant tracking systems.

Do not claim guaranteed compatibility with every ATS provider.

## 10. VIA Resume Page Actions

Display:

**Preview Resume**

Allow the user to preview the generated document.

**Download PDF**

Generate and download the actual PDF file.

The PDF must be generated from the user's latest saved profile data.

Use the existing PDF generation service if available.

Do not create a fake download button or export an image pretending to be a PDF.

If a PDF generator does not exist, implement a reliable PDF generation workflow compatible with the existing MatchMe architecture.

Ensure Arabic text renders correctly and does not appear as disconnected characters.

Use a professional filename such as:

FirstName_LastName_VIA_Resume.pdf

Use a clean form with previously saved values already populated.
