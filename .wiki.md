# Project Summary
MatchMe is an enterprise recruiting platform that matches job seekers and hiring teams with swipe-style compatibility powered by graph-based career intelligence and AI, then drives end-to-end recruiting through governed workflows (messaging, notifications, interviews, pipeline, offer, hire) with measurable analytics and employer subscription monetization.

# Project Module Description
- AI Matching & Career Graph Intelligence: Maintains a career graph (people, companies, roles, skills, education, industries, traits) and provides swipe/reverse matching with explainability and matching APIs.
- Enterprise Governance & API/Events Platform: Provides canonical API/data patterns (gateway, versioning, security, events/webhooks/streaming, analytics conventions) for consistent auditable integrations.
- Hiring Workflow Engine: Converts matches into governed actions (messaging, scheduling, ATS-lite pipeline, offers, collaboration, workflow automation, analytics/event publishing).
- Monetization & Pricing: Manages employer plans, credits and usage-based billing, feature gating, and revenue analytics via lifecycle events.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies (web):
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
