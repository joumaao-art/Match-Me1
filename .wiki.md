# Project Summary
MatchMe is an AI-driven recruitment platform that simplifies and enhances the hiring process for job seekers and employers through an intuitive web and mobile application. The platform leverages intelligent compatibility scoring and a swipe-based interface to improve user engagement. It features a mobile app developed with Expo and a web application built using Vite and React, with a backend powered by Supabase and PostgreSQL. Key functionalities include a messaging system, notification center, subscription plans, analytics, and a premium **Candidate Directory** for advanced recruitment capabilities. Recent enhancements include a dedicated Super Admin Platform for managing the entire ecosystem, integrating authentication, user management, companies, jobs, AI matching, billing, messaging, notifications, analytics, RBAC, and feature flags. A new **Enterprise Navigation Framework** has been introduced to streamline navigation across all portals. The platform has also undergone a comprehensive localization audit to enhance its internationalization (i18n) capabilities.

# Project Module Description
- **Frontend**: Vite and React interface with role-based routing for job seekers, companies, and administrators.
- **Backend**: Supabase for authentication, data management, and real-time processing with a PostgreSQL schema.
- **Mobile App**: Expo and React Native for seamless job discovery and applications.
- **Shared Packages**: TypeScript models, validation schemas, localization, API services, and reusable utilities for web and mobile.
- **Authentication**: Role-based system for secure user management.
- **Internationalization**: Bilingual support (English and Arabic) with RTL and LTR capabilities.
- **Company Dashboard**: Interactive statistics for managing vacancies and applications.
- **Candidate Directory**: Premium feature for evaluating and saving job seekers.
- **Job Seeker Experience**: Enhanced UI for profiles, CVs, and notifications.
- **AI Matching Engine**: Compatibility scoring for job matching.
- **Messaging System**: Controlled messaging based on hiring workflows.
- **Notification Center**: Manages notifications via various channels.
- **Subscription Plans**: Centralized billing engine with multiple tiers and payment integrations.
- **Analytics Dashboard**: Admin portal with KPIs.
- **Role-Based Access Control (RBAC)**: Configurable roles and permissions for management.
- **Super Admin Platform**: Comprehensive management interface for platform administrators, including user impersonation, global search, company verification, job seeker management, subscription management, billing, analytics, notifications, feature flags, and a new **Localization Management Module** for managing translations.
- **Enterprise Navigation Framework**: A shared, configuration-driven navigation system for all MatchMe portals, featuring collapsible sections, permission-based visibility, and smooth animations.

# File Description Inventory
- **app/backend/README.md**: Documentation for backend setup and configuration.
- **app/frontend/README.md**: Documentation for frontend setup and usage instructions.
- **app/frontend/src/App.tsx**: Main application component managing routes and context.

- **app/frontend/src/lib/i18n.ts**: i18n configuration for localization, including fallback mechanisms and missing key tracking.
- **app/frontend/src/lib/notification-center.ts**: Notification system managing events.
- **app/frontend/src/lib/performance.ts**: Utilities for performance optimization.
- **app/frontend/src/lib/security.ts**: Security utilities for input validation.
- **app/frontend/src/pages/**: Various application pages including Admin, Analytics, Company, JobSeeker, LearnMore, Messages, Notifications, ResetPassword, and Subscription.
- **app/frontend/src/services/admin-platform.ts**: Centralized admin platform service for managing the Super Admin functionalities.
- **app/frontend/src/components/shared/EnterpriseNavigation.tsx**: New shared component for enterprise navigation with collapsible sections and configuration-driven menus.
- **app/frontend/src/components/shared/BillingAnalytics.tsx**: Admin dashboard for billing analytics and metrics.
- **app/frontend/src/components/shared/LocalizationManagement.tsx**: New component for managing translations, including a dashboard, editor, and import/export functionalities.

# Technology Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
