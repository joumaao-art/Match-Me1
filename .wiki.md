# Project Summary
MatchMe is an AI-driven recruitment platform that helps job seekers and employers discover compatibility via swipe-style matching, then complete hiring through evaluations, messaging, notifications, analytics, and outcome tracking. The platform enforces reusable “engine” patterns to deliver consistent web/mobile product behavior with security-first enterprise governance, including premium engagement for qualified users.

# Project Module Description
- Workflow Engines (Part 4 specification update)
  - Define orchestration of business processes across MatchMe as reusable, configurable, observable, auditable, event-driven, and versioned workflow execution.
  - Standardize a common internal workflow structure: Workflow → Stages → Steps → Actions → Events, with integrated Notifications, Audit Log, and Analytics.
  - Provide shared standards for workflow state, event emission, notifications, permissions integration, analytics collection, templates, versioning, and recovery.
  - Specify engine relationships so workflow execution remains separate from UI and does not own persistence or presentation.

- Workflow Orchestration (architectural recommendation within spec)
  - Acts as a centralized coordinator for cross-workflow dependencies and chaining without workflows directly calling each other.
  - Manages event routing, parallel execution, branching, escalation, retries, compensating rollbacks, and SLA/workflow health monitoring.

- Spec-defined Workflow Engines
  - Application: job application lifecycle states and transitions.
  - Interview: scheduling, reminders, stages, feedback, scorecards, history, calendar integration.
  - Offer: approval routing, versions, sent/viewed/negotiation/acceptance/decline/expiration.
  - Onboarding: document/proof steps, checklist/progress, notifications, dependencies, completion analytics.
  - Approval: approval chains, delegation, escalation, timeouts, audit history.
  - Recruitment Pipeline: pipeline stage management, ranking/prioritization, bulk actions.
  - CRM: sales pipeline stages, tasks, follow-ups, sales automation, customer history.
  - ATS: applicant tracking movement, collaboration, resume parsing, status tracking.
  - Automation: rules/triggers/conditions, retry/scheduling, execution history.
  - Task: assignments, due dates, priorities, recurring tasks, comments/attachments, notifications.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
