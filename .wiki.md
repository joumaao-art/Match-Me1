# Project Summary
MatchMe is an AI-driven recruitment platform designed to enhance the hiring process for job seekers and employers through a web and mobile application. The platform utilizes intelligent compatibility scoring and a swipe-based interface to improve user engagement. It features a mobile app developed with Expo and a web application built using Vite and React, with a backend powered by Supabase and PostgreSQL. Key functionalities include a messaging system, notification center, subscription plans, performance analytics, and a Profile Completion and Strength system. The platform now includes a premium **Candidate Directory** feature, enabling companies to actively search and save job seekers, thus improving recruitment capabilities. Recent updates have introduced an AI Candidate Recommendation Engine, a Recruiter Invitation System, and enhanced analytics for both job seekers and companies.

# Project Module Description
- **Frontend**: Vite and React-based interface with role-based routing for job seekers, companies, and administrators.
- **Backend**: Supabase for authentication, data management, and real-time processing with a PostgreSQL schema.
- **Mobile App**: Expo and React Native for seamless job discovery and applications for job seekers.
- **Shared Packages**: TypeScript models, validation schemas, localization, API services, and reusable utilities for web and mobile.
- **Authentication**: Role-based system for sign-up, login, email verification, password recovery, and secure sessions.
- **Internationalization**: Bilingual support (English and Arabic) with RTL and LTR capabilities and language persistence.
- **Company Dashboard**: Enhanced with interactive statistic cards for Active Vacancies, Total Applications, Interviews, and Hired candidates.
- **Candidate Directory**: A premium feature enabling companies to discover, evaluate, and save job seekers, integrating with existing architecture and ensuring role-based access.
- **Job Seeker Experience**: UI enhancements including profiles, CVs, experiences, education, certificates, skills, languages, portfolios, video introductions, and notifications.
- **AI Matching Engine**: Compatibility scoring using embeddings and semantic similarity for improved job matching.
- **Messaging System**: Controlled messaging based on hiring workflows with status badges and permissions.
- **Notification Center**: Manages notifications via Email, Push, In-app, and SMS.
- **Subscription Plans**: Multiple tiers (Free, Premium, Premium+) with payment integrations (Stripe, Moyasar, Apple Pay, Google Pay).
- **Analytics Dashboard**: Admin portal with KPIs like Daily Active Users, Matches, Applications, and Conversion Rates.
- **Performance Optimization**: Caching, pagination, virtualization, image optimization, and SEO improvements.
- **Security Module**: Enhanced security features including a secure "Change Password" workflow for all user roles.
- **Profile Completion and Strength System**: Feature providing job seekers with a progress bar, checklist, and recommendations to enhance their profiles for better matching.
- **Navigation Improvements**: Consistent navigation across the application using a reusable BackButton component.
- **Learn More Page**: A marketing page that explains the platform features, benefits, and functionalities for both job seekers and companies.
- **Search and Filter Functionality**: Recently updated to ensure real-time search, combined filtering, sorting, and pagination on the Candidates page.
- **Recruiter Invitation System**: Enables companies to invite candidates to apply for specific job openings, enhancing recruitment workflows.
- **Talent Pipeline Management**: New feature for tracking candidates through various stages, with options for notes and tagging.

# File Description Inventory
- **app/backend/README.md**: Documentation for backend setup and configuration.
- **app/frontend/README.md**: Documentation for frontend setup and usage instructions.
- **app/frontend/src/App.tsx**: Main application component managing routes and context with complete authentication and role-based access.
- **app/frontend/src/lib/ai-matching-engine.ts**: Implementation of the AI-powered matching engine, including scoring mechanisms and explainability.
- **app/frontend/src/lib/i18n.ts**: i18n configuration for localization.
- **app/frontend/src/lib/notification-center.ts**: Notification system managing channels and events.
- **app/frontend/src/lib/performance.ts**: Utilities for performance optimization.
- **app/frontend/src/lib/security.ts**: Security utilities including rate limiting and input validation.
- **app/frontend/src/pages/**: Various application pages including Admin, Analytics, Company, JobSeeker, LearnMore, Messages, Notifications, ResetPassword, and Subscription.
- **app/frontend/src/services/api-client.ts**: API client for interacting with Supabase, handling authentication and data requests.
- **app/frontend/src/services/message.service.ts**: Service for managing messaging operations, including real-time updates and workflow state management.
- **app/frontend/src/types/messaging.types.ts**: Types related to messaging and hiring workflow states.
- **app/frontend/src/components/shared/**: Shared components including BackButton, ChangePassword, CandidateDirectory, CandidateDiscoverability, ProfileCompletion, AITalentIntelligence, and SeekerInvitations for user settings and profile management.
- **app/frontend/src/components/InteractiveStatCard.tsx**: New reusable component for interactive dashboard statistic cards.

# Technology Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
