# Project Summary
MatchMe is an AI-driven recruitment platform that matches job seekers and employers using swipe-style compatibility, then drives hiring via evaluations, messaging, notifications, analytics, and tracked outcomes. The product relies on reusable “engine” patterns with enterprise governance to keep behavior consistent across web and mobile, enforce security and observability, and support premium engagement for qualified users.

# Project Module Description
- Platform Engines Specification (Prompt 4, Parts 1–7)
  - **Part 6 — AI Engines**: Defines modular AI services (matching, recommendations, resume/skills intelligence, copilot, ranking, insights, predictions, summaries, and Knowledge/RAG), with strict governance (permissions, explainability, human override, monitoring) and a single **AI Orchestration Engine** entry point.
  - **Part 7 — Data & Infrastructure Engines (new)**: Defines infrastructure engines that provide the platform backbone (persistence, synchronization, caching, storage, import/export, indexing, async execution, eventing, webhooks, scheduling, gateway, logging, monitoring), explicitly not responsible for UI or business rules.
  - **Platform Fabric Engine (strategic recommendation)**: A connective layer that coordinates engine-to-engine communication, event routing, tracing, config propagation, health aggregation, tenant awareness, and dependency management—acting as a “digital nervous system” while preserving engine independence.
  - **Final platform rule (applies across parts)**: No feature/service/workflow/AI capability may bypass Data & Infrastructure Engines to access infrastructure directly; all future platform services must consume these engines.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
