# Project Summary

MatchMe is a recruiting marketplace connecting job seekers with companies. Job seekers discover vacancies, manage applications, save preferences, and maintain professional profiles; companies publish vacancies and review applicants. Admin tools support marketplace operations. The product supports English and Arabic and uses Supabase for authentication and marketplace data.

Job Seeker workflows are available on mobile and desktop, with mobile as the product-authority baseline. The Swipe experience includes Improve My Match, which provides deterministic, Supabase-backed skill recommendations. Seekers can review and confirm individual skills, save confirmed skills to their canonical profile, and recalculate their vacancy match score through the existing matching engine.

VIA Premium offers monthly and yearly plans. Paid access requires complete Stripe webhook configuration and a verified sandbox transaction; native purchases remain disabled pending approved store billing.

# Project Module Description

- **Authentication and routing:** Signup, login, verification, role-based routes, shared-job authentication recovery, and Supabase sign-out.
- **Onboarding:** Mobile and desktop Job Seeker onboarding, validation, account-isolated draft recovery, and confirmed mobile date entry.
- **Job Seeker Dashboard:** Mobile and desktop navigation, search, application categories and statuses, application details, saved jobs, and skipped-job reconsideration.
- **Swipe and vacancy matching:** Mobile and desktop vacancy decisions, preference and eligibility ranking, credits access, and selected-card navigation. Improve My Match suggests required and preferred skills deterministically, normalizes taxonomy synonyms including CRM terms, and supports per-skill confirmation. It preserves canonical profile saving, matching-engine recalculation, and existing credit rules.
- **Skill Match analysis:** Authenticated Supabase-backed recommendation endpoint with private caching, rate limits, ownership checks, deduplicated saves, and deterministic fallback behavior. No external AI service or API key is used.
- **Appearance settings:** Job Seeker controls for Light Mode, Dark Mode, and System Default, with account-scoped persistence and local caching.
- **Personal profile and skills:** Mobile and desktop editing with shared validation and backend-confirmed saves. Mobile Personal layout uses content-sized scrolling and normal-flow Save controls; desktop behavior remains unchanged. Compensation is optional and private.
- **Professional history:** Experience, Education, and Certification editing. Mobile date selections require confirmation; Current/Present options are retained.
- **Saved Preferences:** Mobile and desktop preference interfaces with persistence across logout and login.
- **Profile, account, and resume:** Account overview, private CV access, canonical profile data, and bilingual VIA Resume PDF generation.
- **Logout:** Confirmation-based Supabase sign-out, account-cache cleanup, error handling, and welcome-page redirect. Persisted user data is retained.
- **Support and settings:** FAQ, persisted issue reporting, and Appearance settings. Unconfigured support providers and unavailable account operations are not presented as functional.
- **Company marketplace:** Company profiles, private logo storage, vacancy drafts and publication, dashboard counts, and applicant review.
- **Applications and matches:** Company review decisions update application statuses and seeker matches.
- **VIA Premium and payments:** Monthly and yearly plans, subscription management, credit access, Stripe checkout, server-side catalog validation, and verified webhook entitlement updates.
- **Shared job links:** Stable vacancy IDs support web landing pages and authentication recovery. Android App Links require deployment configuration.
- **Profiles, messaging, and localization:** Shared profile and history records, existing messaging, English and Arabic translations, and Company/Admin portals. Live chat and unread-count consistency are not established.
- **Validation and parity evidence:** Contract checks cover marketplace behavior, deterministic skill recommendations and saving, appearance persistence, mobile date confirmation and scrolling, icon accessibility, desktop coverage, and known acceptance limitations.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Native app:** Expo and React Native with a shared-screen WebView container
- **Backend and data:** Supabase, Node.js, PostgreSQL, Supabase Edge Functions
- **Authentication:** Supabase Auth
- **State management:** React Context API, Zustand
- **Skill recommendations:** Deterministic Supabase-backed provider; no external AI integration
- **Payments:** Stripe checkout and webhook integration with server-side verification
- **PDFs and fonts:** Browser PDF generation and Amiri Arabic font asset
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, contract checks, and rollback-only database tests

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Validate translations:

   ```bash
   pnpm run check:language
   ```

5. Run the Skill Match contract checks:

   ```bash
   node scripts/skill-match-contract.mjs
   ```

6. Run other feature checks as needed:

   ```bash
   node scripts/personal-scroll-contract.mjs
   node scripts/mobile-date-confirmation-contract.mjs
   node scripts/seeker-appearance-contract.mjs
   node scripts/mobile-icon-contract.mjs
   node scripts/desktop-parity-contract.mjs
   node scripts/seeker-navigation-contract.mjs
   node scripts/live-marketplace-contract.mjs
   node scripts/via-premium-contract.mjs
   ```

7. Configure Supabase and apply the required migrations, including `024_via_skill_match.sql` and `025_deterministic_skill_match.sql`, along with migrations for profiles, private CV storage, Personal categories, and account settings.

8. Deploy the skill-match Supabase function using its deploy bundle. Skill recommendations require no external AI service or API key. Configure Stripe secrets and webhook deployment separately, and verify a sandbox transaction before enabling paid access.

9. Skill Match validation passed 62 contract checks, TypeScript, lint/build, seven rollback-only database checks, and endpoint authentication checks. The signed-in workflow has not completed acceptance testing: 13 requested signed-in workflow checks remain unverified.
