# Project Summary
MatchMe is an enterprise recruiting platform that helps job seekers and hiring teams discover compatible opportunities through swipe-based matching, career intelligence, and AI. It supports governed recruiting workflows including messaging, interviews, pipeline management, offers, hiring, analytics, and employer monetization.

The Job Seeker journey now includes a mobile-first, resumable signup and onboarding experience. New users can authenticate with Apple, Google, phone OTP, or email, create a profile from a resume or manually, configure preferences, review their profile, select a plan, and enter the Discover experience. MatchMe branding and the Company authentication flow remain unchanged.

# Project Module Description
- **Job Seeker Authentication:** Supports Apple, Google, phone OTP, and existing email authentication paths. OAuth users are bootstrapped into MatchMe profiles without creating duplicate accounts.
- **Job Seeker Onboarding Engine:** Centralizes onboarding steps, validation, navigation, persistence, skip rules, completion status, analytics, and resumable progress.
- **Profile Creation:** Supports resume-assisted and manual profile creation using the canonical Job Seeker profile model.
- **Onboarding UI Kit:** Provides reusable layouts, progress indicators, bottom actions, signup method buttons, OTP input, option cards, and profile review elements.
- **Profile Setup:** Collects acquisition source, demographic information, birthday, current location, target countries, notifications, profile review, rating, and job preferences.
- **Discover Transition:** Routes completed users through plan selection and the first-time Discover tutorial before opening the existing swipe experience.
- **Localization:** New signup and onboarding copy supports English, Arabic, and RTL layouts.
- **Company Protection:** Company login and signup behavior remains on the existing authentication path.

# File Description Inventory
- `app/frontend/src/App.tsx`: Registers onboarding routes, authentication callbacks, and post-authentication routing.
- `app/frontend/src/pages/Auth.tsx`: Provides Job Seeker signup methods, phone entry, OTP verification, and preserves the Company login flow.
- `app/frontend/src/pages/JobSeeker.tsx`: Redirects incomplete new Job Seeker profiles into onboarding while allowing completed users into the dashboard.
- `app/frontend/src/pages/JobSeekerOnboarding.tsx`: Renders the progressive onboarding workflow from welcome through Discover preparation.
- `app/frontend/src/lib/onboarding-engine.ts`: Defines onboarding steps, state transitions, validation, persistence, skip behavior, completion, and analytics integration.
- `app/frontend/src/components/onboarding/OnboardingKit.tsx`: Contains reusable onboarding layouts, actions, progress UI, signup controls, OTP input, and selection components.
- `app/frontend/src/services/auth.service.ts`: Implements OAuth and phone OTP authentication integrations.
- `app/frontend/packages/shared/src/constants/index.ts`: Stores shared routes, onboarding constants, and related configuration.
- `app/frontend/packages/shared/src/i18n/en.ts`: English signup and onboarding translations.
- `app/frontend/packages/shared/src/i18n/ar.ts`: Arabic signup and onboarding translations with RTL support.
- `app/frontend/seo/content/*.md`: SEO article content.
- `app/frontend/docs/enterprise/*.md`: Enterprise API, governance, matching, workflow, data, and monetization specifications.

# Technology Stack
- **Frontend:** Vite, React, TypeScript, Tailwind CSS
- **Mobile:** React Native, Expo
- **Backend:** Supabase, Node.js, PostgreSQL
- **State Management:** React Context API, Zustand
- **Authentication:** Supabase Auth with email, OAuth, and phone OTP
- **Internationalization:** i18next with English and Arabic/RTL support
- **Workspace:** pnpm monorepo
- **Build Validation:** TypeScript, ESLint, and production Vite builds

# Usage
1. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
2. Start the frontend:
   ```bash
   pnpm run start
   ```
3. Build the production frontend:
   ```bash
   pnpm run build
   ```
4. Run the mobile application:
   ```bash
   cd app/mobile
   expo start
   ```
5. Configure enabled Supabase providers for Apple, Google, and SMS/OTP before using those production authentication paths.
