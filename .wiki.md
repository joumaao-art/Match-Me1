# Project Summary

MatchMe is a recruiting marketplace connecting job seekers with employers. Job seekers discover vacancies, manage applications, save preferences, and maintain professional profiles; companies publish vacancies and review applicants. Admin tools support marketplace operations. The product supports English and Arabic and uses Supabase for account and marketplace data.

Job Seeker experiences include mobile and desktop workflows for onboarding, dashboards, vacancy discovery, preferences, profile editing, subscriptions, private CV access, and VIA Resume PDF generation. Mobile remains the product-authority baseline; desktop-specific screens reuse canonical services and job actions.

Job Seekers can choose Light Mode, Dark Mode, or System Default from Settings → Appearance on mobile and desktop. The account-owned preference is cached locally and synchronized through the existing settings RPC. The desktop sidebar theme icon has been removed; language selection and navigation order remain unchanged. Company and Admin behavior is unaffected.

Mobile date fields require explicit confirmation before committing selected dates for birthdays, onboarding, and professional history. Existing pickers and save or autosave workflows remain in place. Desktop, Company, Admin, and backend date schemas are unchanged.

VIA Premium offers monthly and yearly plans. Paid access requires complete Stripe webhook configuration and a verified sandbox transaction; native purchases remain disabled pending approved store billing.

# Project Module Description

- **Authentication and routing:** Signup, login, verification, role-based routes, shared-job authentication recovery, and Supabase sign-out.
- **Onboarding:** Mobile and desktop Job Seeker onboarding, validation, and account-isolated draft recovery. Mobile date fields require confirmation before saving.
- **Job Seeker Dashboard:** Mobile and desktop navigation, search, application categories and statuses, application details, saved jobs, and skipped-job reconsideration.
- **Desktop navigation:** Sidebar for Swipe, Dashboard, Profile, Subscription Overview, and Preferences. Profile links to VIA Resume and Personal. Theme selection is in Settings → Appearance.
- **Appearance settings:** Mobile and desktop Job Seeker controls for Light Mode, Dark Mode, and System Default, with account-scoped persistence and local caching.
- **Vacancy discovery and decisions:** Preference-aware matching, eligibility guidance, and persisted actions with ownership, duplicate, credit, and expiry safeguards.
- **Saved Preferences:** Mobile and desktop preference interfaces with persistence across logout and login.
- **Personal profile and skills:** Mobile and desktop editing for Identity, Contact, Current Compensation, Gender, and skills, using shared validation and backend-confirmed saves. Mobile date entry requires confirmation; compensation is optional and private.
- **Professional history:** Mobile Experience, Education, and Certification date fields use confirmation before committing a selection. Current/Present options and existing picker behavior are retained.
- **Profile, account, and resume:** Account overview, private CV access, and bilingual VIA Resume PDF generation.
- **Logout:** Confirmation-based logout with Supabase sign-out, account-cache cleanup, error handling, and welcome-page redirect. Persisted user data is retained.
- **Support and settings:** FAQ, persisted issue reporting, and Appearance settings. Unconfigured support providers and unavailable account operations are not presented as functional.
- **Swipe and credits:** Mobile and desktop vacancy decisions, credits access, selected-card navigation, and read-only Profile Completion indicator.
- **Company marketplace:** Company profiles, private logo storage, vacancy drafts and publication, dashboard counts, and applicant review.
- **Applications and matches:** Company review decisions update application statuses and seeker matches.
- **VIA Premium and payments:** Monthly and yearly plans, subscription management, credit access, Stripe checkout, server-side catalog validation, and verified webhook entitlement updates.
- **Shared job links:** Stable vacancy IDs support web landing pages and authentication recovery. Android App Links require deployment configuration.
- **Profiles, messaging, and localization:** Shared profile and history records, existing messaging, English/Arabic translations, and Company/Admin portals. Live chat and unread-count consistency are not established.
- **Validation and parity evidence:** Contract checks and reports track marketplace behavior, appearance persistence, mobile date confirmation, desktop coverage, mobile preservation, and known acceptance limitations.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Native app:** Expo and React Native with a shared-screen WebView container
- **Backend and data:** Supabase, Node.js, PostgreSQL
- **Authentication:** Supabase Auth
- **State management:** React Context API, Zustand
- **Payments:** Stripe checkout and webhook integration with server-side verification
- **PDFs and fonts:** Browser PDF generation and Amiri Arabic font asset
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, contract checks, and rollback-only database tests

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Validate translations:

   ```bash
   pnpm run check:language
   ```

5. Run appearance settings regression checks:

   ```bash
   node scripts/seeker-appearance-contract.mjs
   ```

6. Run mobile date confirmation checks:

   ```bash
   node scripts/mobile-date-confirmation-contract.mjs
   ```

7. Run other relevant contract checks:

   ```bash
   node scripts/desktop-parity-contract.mjs
   node scripts/seeker-navigation-contract.mjs
   node scripts/live-marketplace-contract.mjs
   node scripts/via-premium-contract.mjs
   node scripts/savings-preferences-contract.mjs
   node scripts/mobile-swipe-contract.mjs
   node scripts/mobile-dashboard-contract.mjs
   node scripts/mobile-onboarding-contract.mjs
   node scripts/mobile-profile-contract.mjs
   node scripts/mobile-logout-contract.mjs
   node scripts/personal-information-contract.mjs
   ```

8. Configure Supabase and apply required migrations for Profile persistence, private CV storage, Personal categories, and account settings.

9. Deploy payment functions with the required Stripe secrets. Complete webhook configuration and verify a sandbox transaction before enabling paid access. Android App Links require deployment-specific domain association, package and signing fingerprints, and device/build access. Native purchases remain disabled pending approved store billing.

10. Appearance changes passed 67 automated checks, TypeScript, lint, and production build validation. Mobile date confirmation passed its checks, TypeScript, lint, and production build validation; signed-in mobile scrolling, saves, and refresh/login persistence remain unverified. Desktop navigation authenticated acceptance also remains unverified.
