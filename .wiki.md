# Project Summary
MatchMe is an AI-driven recruitment platform designed to streamline the hiring process for job seekers and employers via a responsive web and mobile application. It employs intelligent compatibility scoring and a swipe-based interface to enhance user engagement. The platform features a mobile app for job seekers built with Expo and a unified web application developed using Vite and React. The backend is powered by Supabase, utilizing a PostgreSQL database with role-based access and a comprehensive company dashboard. The AI matching engine enhances candidate-job alignment by providing explainable recommendations and adaptive learning. Core functionalities include a messaging system, notification center, subscription plans with payment options, and performance analytics. Recent updates have improved security, performance, and navigation consistency across the application.

# Project Module Description
- **Frontend**: Vite and React-based interface with role-based routing for job seekers, companies, and administrators.
- **Backend**: Supabase for authentication, data management, and real-time processing with a PostgreSQL schema.
- **Mobile App**: Expo and React Native for seamless job discovery and application for job seekers.
- **Shared Packages**: TypeScript models, validation schemas, localization, API services, and reusable utilities for web and mobile.
- **Authentication**: Role-based system for sign-up, login, email verification, password recovery, and secure sessions.
- **Internationalization**: Bilingual support (English and Arabic) with RTL and LTR capabilities and language persistence.
- **Company Dashboard**: Tools for profile management, job posting, candidate tracking, analytics, and team management.
- **Job Seeker Experience**: UI enhancements including profiles, CVs, experiences, education, certificates, skills, languages, portfolios, video introductions, and notifications.
- **AI Matching Engine**: Compatibility scoring using embeddings and semantic similarity for improved job matching.
- **Messaging System**: Real-time messaging with read receipts, typing indicators, file sharing, and archiving.
- **Notification Center**: Manages notifications via Email, Push, In-app, and SMS.
- **Subscription Plans**: Multiple tiers (Starter, Professional, Business, Enterprise) with payment integrations (Stripe, Moyasar, Apple Pay, Google Pay).
- **Analytics Dashboard**: Admin portal with KPIs like Daily Active Users, Matches, Applications, and Conversion Rates.
- **Performance Optimization**: Caching, pagination, virtualization, image optimization, and SEO improvements.
- **Security Module**: Rate limiting, input validation, XSS protection, SQL injection prevention, and compliance with OWASP standards.
- **Navigation Improvements**: Consistent navigation across the application using a reusable BackButton component.

- **app/backend/README.md**: Documentation for backend setup and configuration.

- **app/frontend/src/pages/Subscription.tsx**: Updated subscription page with role-specific subscription logic.

- **app/frontend/src/components/shared/BackButton.tsx**: Reusable Back Navigation component for consistent navigation across the application.

# Technology Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
