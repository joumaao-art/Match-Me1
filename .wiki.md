# Project Summary

MatchMe is an enterprise recruiting platform connecting job seekers with employers through job discovery, applications, career tools, and recruiting workflows. It supports job seeker and company accounts, onboarding, messaging, interviews, offers, analytics, and English/Arabic localization.

The Job Seeker profile area has been restructured to bring profile details, resume management, experience, education, certificates, and languages into a more consistent workflow. The new screens include searchable location fields, required-field feedback, date-range controls, chronological history, and total experience calculation. These changes are not yet fully integrated with database persistence, onboarding, profile completeness, AI matching, Career Graph, or candidate search.

# Project Module Description

- **Authentication and routing:** Provides authentication and guarded Job Seeker and Company routes. Legacy Resume and Certificates links open Profile and Education respectively.
- **Job Seeker profile:** Consolidates Resume & CV management into Profile. Country and City use searchable selectors; City options depend on Country. Nationality supports multiple selections and remains distinct from current location.
- **Experience:** Provides standardized employment options, month/year date ranges, current-role support, required-field feedback, description guidance, and a 250-word limit. Entries are sorted newest first, and total experience merges overlapping date ranges.
- **Education and certificates:** Removes GPA from the Education UI without deleting historical values. Education supports current study and a Not Applicable degree option. Certificates appear within Education and remain a separate record type.
- **Languages:** Replaces displayed Advanced proficiency with Fluent and adds Native Speaker.
- **Location data:** Provides a shared country registry and country-specific city files. City data is loaded by country rather than bundled as one worldwide dataset.
- **Localization:** New profile text is available in English and Arabic, with direction-aware layouts intended to support RTL.
- **Persistence and integration status:** The restructured profile data is currently saved in browser storage on the device. The database migration is written but has not been applied to the live database. Onboarding, profile completeness, AI matching, Career Graph, and candidate search integration remain incomplete or unverified.

# File Description Inventory

- `app/frontend/src/components/seeker/ProfessionalProfile.tsx`: Implements the consolidated Job Seeker professional profile views, including Resume within Profile and Certificates within Education.
- `app/frontend/src/components/shared/ProfileFields.tsx`: Provides shared profile controls, including searchable country/city selection, nationality selection, required-field presentation, and date-range input.
- `app/frontend/src/lib/profile-standards.ts`: Contains profile-standardization helpers, including chronological ordering and overlapping-period experience calculations.
- `app/frontend/src/pages/JobSeeker.tsx`: Integrates the restructured views and updates Job Seeker navigation and legacy links.
- `app/frontend/public/geo/countries.json` and `app/frontend/public/geo/cities/*.json`: Supply the country registry and country-specific city data.
- `app/frontend/scripts/build-geo-data.mjs`: Builds the public location data files.
- `app/frontend/packages/shared/src/i18n/en.ts` and `app/frontend/packages/shared/src/i18n/ar.ts`: Provide English and Arabic copy for the profile changes.
- `app/frontend/supabase/migrations/011_profile_standardization.sql`: Defines additive database changes and language proficiency mapping. It has not been applied to or verified against the live database.
- `app/frontend/src/lib/onboarding-engine.ts`: Defines onboarding steps and progress handling; onboarding has not yet been switched to the new shared location controls.
- `app/frontend/scripts/runtime-onboarding-isolation.mjs`: Checks onboarding progress isolation and new-user Welcome behavior.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Mobile:** React Native, Expo
- **Backend and data:** Supabase, Node.js, PostgreSQL
- **State management:** React Context API, Zustand
- **Authentication:** Supabase Auth, including email, OAuth, and phone OTP
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, browser diagnostics, and language scanning

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Start the mobile application:

   ```bash
   cd app/mobile
   expo start
   ```

5. Run language validation:

   ```bash
   cd app/frontend
   pnpm run check:language
   ```

6. Run onboarding isolation and Job Seeker diagnostics:

   ```bash
   cd app/frontend
   node scripts/runtime-onboarding-isolation.mjs
   node scripts/runtime-seeker-navigation.mjs
   node scripts/runtime-seeker-account-states.mjs
   ```

7. Run authentication and signup diagnostics:

   ```bash
   cd app/frontend
   node scripts/runtime-auth-matrix.mjs
   node scripts/runtime-signup-e2e.mjs
   ```

8. Configure Supabase providers, redirects, session persistence, database policies, and required environment variables before provider-specific testing. Apply and verify migrations before relying on database-backed features. The restructured profile data is currently saved in browser storage rather than persisted to the database.
