# Project Summary

MatchMe is an enterprise recruiting platform connecting Job Seekers with employers through job discovery, applications, career profiles, messaging, and recruiting workflows. It supports Job Seeker, Company, and Admin experiences, with English and Arabic localization.

Mobile Job Seeker onboarding is a dedicated 11-step journey with account-isolated autosave, progress recovery, and a completion path to Discover. Recent refinements improve mobile form labels and date-wheel behavior without changing the step sequence or desktop onboarding layout. Discover uses live job records and account-owned actions.

Credits are shared across mobile and desktop. New Job Seeker identities receive 20 credits through the centralized backend grant path; confirmed missing grants can be repaired idempotently, while existing balances are preserved. Credit transactions use the account ledger.

Release readiness remains limited by missing approved legal content, Stripe purchase configuration, and incomplete authenticated mobile and cross-device acceptance. Arabic/RTL and desktop onboarding regression also remain unverified. Automatic location lookup requires configuration; manual location selection remains available. CV extraction currently supports TXT only.

# Project Module Description

- **Authentication and routing:** Signup, login, verification, role-based routes, and desktop flows. Mobile entry uses a dedicated onboarding route.
- **Mobile onboarding:** The 11 semantic steps are `PERSONAL_DETAILS`, `GENDER`, `BIRTHDAY`, `CURRENT_LOCATION`, `SKILLS`, `EDUCATION`, `EXPERIENCE`, `PREFERENCES`, `SENIORITY`, `FREE_CREDITS`, and `HOW_IT_WORKS`. Intro and completion screens are separate from the counted steps.
- **Onboarding persistence:** Saves drafts separately from completed steps, validates before completion, supports retry and recovery, and isolates cached data by account. Existing profile headline and summary values are retained.
- **Mobile controls:** Provides accessible selection and date controls. The education date wheel uses corrected row geometry and chronological year indexing, with controlled selection and month/year preservation.
- **Profiles and preferences:** Mobile onboarding shares canonical profile and history records with account editors. Preferences keep roles, keywords, working style, work type, and seniority as distinct signals.
- **Discover and job actions:** Loads real vacancies and persists swipe, apply, save, and share actions to account-owned records. Job actions and credit deductions are server-backed.
- **Credits and subscriptions:** Shows shared account balance and transaction history. Signup grants and repairs use the existing ledger with duplicate protection. Purchases require configured Stripe pricing and verified fulfillment.
- **Location and localization:** Manual country and dependent-city selection is available. Consent-based reverse geocoding requires provider configuration. English and Arabic translations are maintained; updated mobile RTL behavior still needs acceptance testing.
- **Company and Admin portals:** Existing portal functionality and desktop presentation are preserved.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Mobile:** Mobile web/app experience; React Native and Expo are also present in the project
- **Backend and data:** Supabase, Node.js, PostgreSQL
- **State management:** React Context API, Zustand
- **Authentication:** Supabase Auth
- **Payments:** Stripe integration with server-side verification; configuration required
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, onboarding contract checks, and database tests

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Run language validation:

   ```bash
   pnpm run check:language
   ```

5. Run mobile onboarding contract checks:

   ```bash
   node scripts/mobile-onboarding-contract.mjs
   ```

6. Run available runtime diagnostics:

   ```bash
   node scripts/runtime-onboarding-isolation.mjs
   node scripts/runtime-seeker-navigation.mjs
   node scripts/runtime-seeker-account-states.mjs
   node scripts/runtime-auth-matrix.mjs
   node scripts/runtime-signup-e2e.mjs
   ```

7. Configure Supabase, database policies, Stripe prices and secrets, and any location provider credentials before testing those integrations. Apply the required migrations. Supply approved legal copy before release.

Code and backend validation passed, including 31 contract checks, TypeScript, ESLint, production build, and rollback-only database tests for initial credits, repeat-claim idempotency, legacy-balance preservation, and retained profile data. Authenticated mobile acceptance, Arabic RTL gestures, cross-device behavior, and desktop onboarding regression remain unverified.
