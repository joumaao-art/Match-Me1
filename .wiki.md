# Project Summary

MatchMe is an enterprise recruiting platform connecting job seekers with employers through job discovery, applications, career tools, and recruiting workflows. It supports Job Seeker and Company accounts, onboarding, messaging, interviews, offers, analytics, and English/Arabic localization.

Job Seeker onboarding steps 1, 6, 7, and 10 now reuse shared profile, location, and preference selectors. Onboarding can collect a required highest-education selection, country and city, target countries, target roles, and employment types. On completion, target countries, roles, and employment types are merged into the existing Preferences record. Target countries also contribute to job matching.

Important limitations remain: onboarding Education does not create an Education history record, and the updated steps have not been tested in a real signed-in session, across mobile or desktop sizes, or in Arabic RTL. Preference data is stored in browser storage; roles, target countries, and employment types are also written to the Job Seeker profile. Real-user onboarding, refresh/resume, and account synchronization still require verification.

# Project Module Description

- **Authentication and routing:** Provides authentication and guarded Job Seeker and Company routes. Onboarding step order and the final App Experience Rating step remain unchanged.
- **Job Seeker navigation and Dashboard:** Provides account navigation and Dashboard destinations. Some dashboard counts use sample data.
- **Profile and Education:** Provides professional profile and Education views. Onboarding reuses shared degree data for Highest Education, but does not add an Education history record.
- **Onboarding:** Steps 1, 6, 7, and 10 use shared profile, location, and preference selectors. Step 1 requires a Highest Education selection. Step 6 uses country-dependent city choices. Step 7 supports searchable multi-country selection. Step 10 supports role selection and multiple employment types. Onboarding initialization and progress handling remain in the existing onboarding engine.
- **Preferences:** Provides preferred roles, employment types, and target countries. Onboarding roles, target countries, and employment types are merged into this existing preference record on completion. Preferences use browser storage.
- **Discover and matching:** Provides job discovery and matching. Target countries now contribute to job-match scoring; broader integration of role and employment-type preferences remains limited.
- **Experience, education, and languages:** Provides professional history, education, certificates, and language proficiency. Shared taxonomies and profile controls support consistent data entry.
- **Location and localization:** Shared country and city data supports location controls. English and Arabic translations are available; updated onboarding RTL behavior has not been verified.

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Start the mobile application:

   ```bash
   cd app/mobile
   expo start
   ```

5. Run language validation:

   ```bash
   cd app/frontend
   pnpm run check:language
   ```

6. Run onboarding and Job Seeker diagnostics:

   ```bash
   cd app/frontend
   node scripts/runtime-onboarding-isolation.mjs
   node scripts/runtime-seeker-navigation.mjs
   node scripts/runtime-seeker-account-states.mjs
   ```

7. Run authentication and signup diagnostics:

   ```bash
   cd app/frontend
   node scripts/runtime-auth-matrix.mjs
   node scripts/runtime-signup-e2e.mjs
   ```

8. Configure Supabase providers, redirects, database policies, and required environment variables before provider-specific testing. Verify database migrations before relying on database-backed features. Preferences are stored in browser storage.
