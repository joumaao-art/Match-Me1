# Project Summary
MatchMe is an AI-driven recruitment platform that connects job seekers and employers through swipe-based discovery and compatibility scoring, then supports evaluation, communication, and outcome tracking. It delivers messaging, notifications, analytics, and subscriptions, including a premium Candidate Directory, with reusable “engine” patterns to keep UX consistent across web and mobile behind an enterprise security-first backend.

# Project Module Description
- Web Frontend (app/frontend)
  - Role-based portals (Job Seeker, Company, Admin) with shared UI and engine-driven interaction patterns.
  - Shared libraries for AI matching/scoring logic, notifications, performance/security helpers, and feature registry.
  - Internationalization and RTL/LTR support (English and Arabic).
- Mobile App (app/mobile)
  - Expo + React Native app for swipe-based discovery aligned with shared interaction standards and constants/config.
- Shared Packages (app/frontend/packages/shared)
  - Shared TypeScript models, validation, i18n, constants, and utilities for consistent web/mobile behavior.
- Enterprise Documentation
  - Governance for reusable “engines” and platform consistency, plus a centralized Design System and Component Library specifications.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
   - Run `npm install` in `app/mobile`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: `pnpm run start` in `app/frontend`
   - Mobile: `expo start` in `app/mobile`
