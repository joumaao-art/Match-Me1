# Project Summary
MatchMe is an AI-driven recruitment platform that helps job seekers and employers discover compatibility matches through swipe-based discovery, then supports hiring with evaluations, messaging, notifications, analytics, and tracked outcomes. It provides consistent web and mobile experiences using a reusable, engine-based architecture with security-first enterprise governance, including premium directory experiences for qualified engagement.

# Project Module Description
- Web Frontend
  - Role-based portals for Job Seeker, Company, and Admin using shared engine-aligned interaction patterns.
  - Shared libraries for AI matching/scoring, notifications, security helpers, and a feature registry.
  - i18n with RTL/LTR support (English and Arabic) across pages and components.
- Mobile App
  - Expo + React Native swipe-based discovery aligned with shared interaction constants/config.
- Shared Packages
  - Shared TypeScript models, validation, i18n, constants, and utilities to keep web/mobile behavior consistent.
- Enterprise Documentation
  - Governance and standards for reusable “engine” patterns, including the Design System, Component Library, and the official Platform Engines architecture (now extended with Foundation Engines).

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
   - Run `npm install` in `app/mobile`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: `pnpm run start` in `app/frontend`
   - Mobile: `expo start` in `app/mobile`
