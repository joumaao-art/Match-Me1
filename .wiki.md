# Project Summary
MatchMe is an AI-driven recruitment platform that matches job seekers and employers using swipe-style compatibility, then completes hiring via evaluations, messaging, notifications, analytics, and outcome tracking. The platform uses reusable “engine” patterns (with enterprise governance) to ensure consistent behavior across web and mobile, improve security, and support premium engagement for qualified users.

# Project Module Description
- Platform Engines Specification (Part 5 — Business Engines)
  - Defines Business Engines as reusable, independent, observable, secure, configurable, versioned, API-first, event-driven, scalable, and multi-tenant services.
  - Establishes that Business Engines provide shared business capabilities across portals/modules/workflows/AI/integrations, without orchestrating process flows (that responsibility remains with Workflow Engines).
  - Specifies Business Domain ownership (identity, organizations, permissions, subscriptions, billing, messaging, notifications, files/media, calendar, configuration, search, audit, activity, and feature management).
  - Standardizes cross-engine behavior via:
    - Business event emission (events integrate with Workflow Engines and Analytics).
    - Security and validation requirements (authentication/authorization, audit logging, encryption, rate limiting, privacy, multi-tenancy, and compatibility checks).
  - Introduces a recommendation for a Business Capability Orchestrator to coordinate interactions between Business Engines through event routing and dependency tracking, avoiding direct dependencies.
  - Explicitly enumerates 16 Business Engines: Authentication, Authorization, Permissions, Organization, Subscription, Billing, Messaging, Notification, Calendar, Search, File, Media, Activity, Audit, Configuration, Feature Registry.
  - Defines a relationship model: Foundation → Experience → Workflow → Business, with Business Engines exposing capabilities and not rendering UI.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
