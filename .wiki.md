# Project Summary
MatchMe is an enterprise recruiting platform that matches job seekers and hiring teams using swipe-style compatibility plus AI, then runs end-to-end recruiting via governed workflows, messaging/notifications, analytics, and measurable hiring outcomes.

# Project Module Description
## Platform Reference Implementation (Prompt 4C)
Canonical end-to-end blueprint for composing platform layers (experience engines, workflow/business/AI/security engines, and infrastructure/operations), including core journeys, engine dependency directionality, composition guidance, registries/governance assets, operational dashboards, and deployment/disaster recovery conventions.

## Enterprise Data Platform Specification (Prompt 5)
Enterprise data architecture defining storage, organization, governance, security, quality, lifecycle, and accessibility across enterprise products; includes canonical data modeling, multi-tenant isolation, audit/retention expectations, search integration, AI readiness metadata, and validation gates.

## Canonical Entity Model (Prompt 5 Part 2)
Authoritative platform-wide definitions for business entities with versioned/documented relationships and validation rules; modules must reference canonical schemas/APIs/workflows/AI/search/analytics.

## Relationship & Domain Modeling (Prompt 5 Part 3)
Defines bounded domains, relationship types, aggregate roots, ownership, cardinality, referential integrity, lifecycle/cascade rules, cross-domain communication rules, and a relationship registry/validation process.

## Database Standards & Naming Conventions (Prompt 5 Part 4)
Official database engineering standards covering naming conventions and engineering rules for schemas, tables, columns, constraints, indexes, views/materialized views, functions, triggers, and migrations, including security/audit/documentation/validation expectations.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies (web):
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
