# Project Summary
MatchMe is an AI-driven recruitment platform that matches job seekers and employers via swipe-style compatibility, then drives hiring through evaluations, messaging, notifications, analytics, and tracked outcomes. The platform uses reusable engine patterns with enterprise governance to keep behavior consistent across web and mobile, improve security, and support premium engagement for qualified users.

# Project Module Description
- Platform Engines Specification (Part 6 — AI Engines)
  - Defines AI Engines as modular, explainable, configurable, observable, secure, reusable, versioned, and API-first services.
  - Establishes AI Layer scope (intelligence that enhances user experience and hiring outcomes) while enforcing the rule that AI augments human decision-making and never replaces deterministic platform rules.
  - Introduces AI architecture layering:
    - Experience/Workflow engines produce interaction and process; AI Engines provide intelligence.
    - AI remains isolated from presentation and relies on a Knowledge Layer and Models/Data Platform.
  - AI domain ownership includes:
    - Matching, recommendations, ranking, resume intelligence, skills intelligence, insights, predictions, conversational AI, summaries, learning, and automation assistance.
  - Standardizes cross-cutting AI requirements:
    - AI context is permission-, role-, subscription-, localization-, and feature-flag aware.
    - Explainability for recommendations (why, confidence, factors, alternatives, feedback).
    - Human override capabilities (ignore/reject/override/retry/feedback).
    - Responsible AI monitoring (bias, fairness, drift, hallucinations, privacy, security, performance, accuracy).
    - Governance requirements (owner, purpose, versioning, training data source, evaluation/monitoring, rollback, approval, documentation).
    - AI events emission for Analytics and Workflow integration.
    - Validation steps (model evaluation, security/privacy/bias assessment, explainability/performance/integration/documentation review).
  - Adds a strategic recommendation:
    - An AI Orchestration Engine as the single entry point for all AI capabilities, responsible for routing, model/prompt selection and versioning, caching, permission/privacy checks, RAG coordination via Knowledge Engine, monitoring (latency/cost/quality), fallback behavior, audit logging, and controlled rollouts.
  - Specifies 10 AI Engines:
    1. AI Matching Engine
    2. Recommendation Engine
    3. Resume Intelligence Engine
    4. Skills Intelligence Engine
    5. AI Copilot Engine
    6. Ranking Engine
    7. Insights Engine
    8. Prediction Engine
    9. AI Summary Engine
    10. Knowledge Engine (RAG, semantic search, source attribution)

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
