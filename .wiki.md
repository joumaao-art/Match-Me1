# Project Summary
MatchMe is an AI-driven recruitment platform that helps job seekers and employers discover, evaluate, and match talent through a swipe-based experience and compatibility scoring, backed by a secure enterprise-ready backend. The product includes messaging, notifications, subscriptions, analytics, and a premium Candidate Directory, with reusable “engines” that standardize decisions, scoring visualizations, and mobile swipe feedback for consistent UX.

# Project Module Description
- Frontend (Web): Vite + React + TypeScript app with role-based routing for job seekers, companies, and administrators.
- Mobile App: Expo + React Native app for job discovery and swipe-based decisions.
- Shared Packages: TypeScript shared models/validation/i18n/constants/utilities used across web and mobile.
- Core Engines (shared patterns/components):
  - Universal Card Engine for card-based UI patterns
  - Decision/Swipe UI (including Swipe Feedback Engine) for evaluation interactions
  - ScoreVisualizationEngine for consistent AI score/KPI rendering
  - Feature Registry for configuration-driven feature access
  - AI Matching Engine for compatibility scoring
- Platform Capabilities:
  - Messaging, notification center, analytics dashboard, subscription plans/billing, and RBAC/security utilities
  - i18n with English/Arabic and RTL/LTR support

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
   - Run `npm install` in `app/mobile`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Frontend: `pnpm run start` in `app/frontend`
   - Mobile: `expo start` in `app/mobile`
