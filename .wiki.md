# Project Summary

MatchMe is a recruiting marketplace where job seekers discover vacancies, manage applications, and connect with employers, while companies publish roles and review applicants. It supports Job Seeker, Company, and Admin experiences, English and Arabic, and uses Supabase to persist marketplace activity.

The mobile Job Seeker experience includes vacancy discovery, applications, saved jobs, and a redesigned Profile with account details, professional information, subscription overview, private CV access, and VIA Resume PDF generation. Desktop Profile layout and canonical billing data are preserved. Official support chat/email, secure login-phone changes, and account deletion are not available and are not simulated.

VIA Premium offers monthly and yearly plans ($10/month and $100/year), with yearly savings displayed. Paid access still requires complete Stripe webhook configuration and a verified sandbox transaction. Native purchases remain disabled pending approved store billing.

Validation has passed for TypeScript, lint, production build, 103 contract checks, and rollback-only database persistence and security checks. Authenticated mobile Profile acceptance remains incomplete, and Arabic PDF visual confirmation is inconsistent.

# Project Module Description

- **Authentication and routing:** Signup, login, verification, role-based routes, and shared-job authentication recovery.
- **Mobile onboarding:** Eleven semantic onboarding steps with account-isolated draft recovery, validation, and derived birthday age display.
- **Job Seeker Dashboard:** Mobile navigation, search, application categories and statuses, application details, saved-job actions, and skipped-job reconsideration.
- **Vacancy discovery and decisions:** Vacancy ranking and fallback, preference-aware matching, eligibility guidance, and persisted actions with ownership, duplicate, credit, and expiry safeguards.
- **Saved Preferences:** Mobile preferences UI and persistence across logout and login.
- **Mobile Profile:** Account overview, Personal editing, saved professional skills, subscription overview, private CV upload/access, bilingual VIA Resume PDF preview and download, FAQ, issue reporting, and settings. Desktop Profile is unchanged.
- **Company marketplace:** Persisted Company profiles, private logo storage, vacancy drafts and publication, dashboard counts, and applicant review.
- **Applications and matches:** Company review decisions update application statuses and seeker matches.
- **VIA Premium and credits:** Credits popup, monthly/yearly plan selection, subscription management, and server-derived Premium eligibility. Yearly is the fresh-page default; pending checkouts retain their selected plan.
- **Payments and entitlements:** Stripe checkout and verification use server-side catalog validation; subscription lifecycle updates require verified webhook signatures.
- **Shared job links:** Stable vacancy IDs support web landing pages and authentication recovery. Android App Links require deployment configuration.
- **Profiles, messaging, and localization:** Shared profile and history records, existing messaging, English/Arabic translations, and Company/Admin portals. Live chat and unread-count consistency are not established.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **PDF generation:** Browser-side PDF generation with English and Arabic font support
- **Native app:** Expo and React Native, with a shared-screen WebView container
- **Backend and data:** Supabase, Node.js, PostgreSQL
- **Authentication:** Supabase Auth
- **State management:** React Context API, Zustand
- **Payments:** Stripe checkout and webhook integration with server-side verification
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, contract checks, and rollback-only database tests

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Validate translations:

   ```bash
   pnpm run check:language
   ```

5. Run the mobile Profile contract:

   ```bash
   node scripts/mobile-profile-contract.mjs
   ```

6. Run the existing marketplace, Premium, preferences, Swipe, navigation, Dashboard, and onboarding contracts:

   ```bash
   node scripts/live-marketplace-contract.mjs
   node scripts/via-premium-contract.mjs
   node scripts/savings-preferences-contract.mjs
   node scripts/mobile-swipe-contract.mjs
   node scripts/seeker-navigation-contract.mjs
   node scripts/mobile-dashboard-contract.mjs
   node scripts/mobile-onboarding-contract.mjs
   ```

7. Configure Supabase and apply the required migrations, including `022_mobile_profile.sql`, before using the Profile persistence and private CV storage workflows. Deploy payment functions with the required Stripe secrets. Complete webhook configuration and verify a sandbox transaction before enabling paid access.

8. Android App Links require deployment-specific domain association, package and signing fingerprints, and device/build access. Native purchases remain disabled pending approved store billing.
