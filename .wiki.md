# Project Summary
MatchMe is an AI-driven recruitment platform that streamlines the hiring process by effectively connecting job seekers with employers through a responsive web and mobile application. The platform leverages intelligent compatibility scoring and a swipe-based interface to enhance user experience for candidates and companies. It features a mobile app for job seekers developed with Expo and a unified web application built using Vite and React. The backend is powered by Supabase, providing a robust PostgreSQL database, role-based access, comprehensive authentication, and a detailed company dashboard. The integrated AI-powered matching engine uses embeddings and semantic similarity to optimize candidate-job matching based on various factors, delivering explainable recommendations and adaptive learning over time. A newly developed messaging system enhances communication between users. 

The platform now includes a comprehensive notification center that manages various channels and events, ensuring users stay informed.

# Project Module Description
- **Frontend**: Developed with Vite and React, featuring role-based routing for job seekers, companies, and administrators.
- **Backend**: Utilizes Supabase for authentication, database management, and real-time data handling, with a comprehensive PostgreSQL schema.
- **Mobile App**: Built with Expo and React Native, providing a seamless experience for job seekers to discover and apply for jobs.
- **Shared Packages**: Contains TypeScript models, validation schemas, localization, API services, and reusable utilities for both web and mobile applications.
- **Authentication**: Complete role-based authentication system including sign-up, login, email verification, password recovery, and secure sessions.
- **Internationalization**: Full bilingual support for English and Arabic, including RTL and LTR support, language switcher, and persistence of language preferences.
- **Company Dashboard**: Comprehensive management tools for companies, including profile management, job posting, candidate tracking, analytics, and team management.
- **Job Seeker Experience**: Enhanced user interface for job seekers with features including Profile, CV, Experience, Education, Certificates, Skills, Languages, Portfolio, Video Introduction, Preferences, Saved Jobs, Applications, Matches, Messages, Notifications, and Settings.
- **AI-Powered Matching Engine**: Implements embeddings and semantic similarity for compatibility scoring based on factors such as skills, experience, education, languages, salary, location, industry, work preference, remote/hybrid/office policies, and availability, returning a compatibility score from 0-100 and providing explanations for recommendations.
- **Messaging System**: A complete messaging system with features such as real-time messaging, read receipts, typing indicators, file sharing, CV sharing, image sharing, push notifications, conversation archiving, user blocking, and reporting.
- **Notification Center**: A comprehensive notification system with channels for Email, Push, In-app, and SMS. It supports events like New Match, Interview, Message, Application, Company Invite, Job Expiry, Subscription, and Admin Notice, along with features for notification history, priority management, and user preferences.

# Technology Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
