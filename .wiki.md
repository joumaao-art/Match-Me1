# Project Summary
MatchMe is an AI-driven recruitment platform that helps job seekers and employers discover matches via swipe-based interaction, rank compatibility with AI scoring, and complete the full hiring loop with evaluation, messaging, notifications, analytics, and tracked outcomes—plus premium directory experiences. The platform maintains consistent UX across web and mobile through a reusable “engine” approach backed by an enterprise-grade, security-first architecture.

# Project Module Description
- Web Frontend (app/frontend)
  - Role-based portals for Job Seeker, Company, and Admin with shared engine-driven interaction patterns.
  - Shared libraries for AI matching/scoring, notifications, security helpers, and feature registry.
  - i18n with RTL/LTR support (English and Arabic) and consistent interaction standards across pages.
- Mobile App (app/mobile)
  - Expo + React Native app implementing swipe-based discovery aligned to shared interaction constants/config.
- Shared Packages (app/frontend/packages/shared)
  - Shared TypeScript models, validation, i18n, constants, and utilities to keep web/mobile behavior consistent.
- Enterprise Documentation (app/docs/enterprise)
  - Governance and standards for reusable “engine” patterns, plus Design System and Component Library specifications.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
   - Run `npm install` in `app/mobile`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: `pnpm run start` in `app/frontend`
   - Mobile: `expo start` in `app/mobile`
