# Project Summary
MatchMe is an enterprise recruiting platform that matches job seekers and hiring teams using swipe-style compatibility plus AI, then executes end-to-end recruiting via governed workflows, messaging/notifications, analytics, and measurable hiring outcomes.

# Project Module Description
- Platform Reference Implementation (Prompt 4C): Canonical end-to-end blueprint for composing platform layers (experience engines, workflow/business/AI/security engines, infrastructure/operations), including core journeys, governance assets, operational conventions, and deployment/disaster recovery guidance.
- Enterprise Data Platform Specification (Prompt 5): Enterprise data architecture covering storage, organization, governance, security, quality, lifecycle, accessibility, and integration/AI-readiness metadata.
- Search & Indexing Architecture (Prompt 5 Part 6): Enterprise search platform definition covering search/index architecture, governance, tenant/permission-aware security, ranking and filtering, index lifecycle and update strategies, search APIs, analytics, AI search readiness, and performance targets.
- Canonical Entity Model (Prompt 5 Part 2): Authoritative platform-wide business entity definitions with versioned/documented relationships and validation rules.
- Relationship & Domain Modeling (Prompt 5 Part 3): Bounded domains, relationship types, aggregates, ownership, cardinality, lifecycle/cascade rules, cross-domain communication rules, and a relationship registry/validation process.
- Database Standards & Naming Conventions (Prompt 5 Part 4): Official database engineering standards for schemas/tables/columns/constraints/indexes/views/functions/triggers and migrations, including security/audit/documentation/validation expectations.
- Multi-Tenant & Row-Level Security (Prompt 5 Part 5): Defines tenant hierarchy, resource ownership, visibility levels, row-level security requirements, and a centralized security-resolution approach that all tables/entities/APIs/AI/search/analytics must inherit.
- Analytics & Reporting Data Platform (Prompt 5 Part 7): Single enterprise analytics architecture that transforms event/operational data into governed, tenant-aware, versioned metrics, reports, dashboards, forecasts, and AI insights via a shared pipeline and registries.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies (web):
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
