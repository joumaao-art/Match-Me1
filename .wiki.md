# Project Summary
MatchMe is an AI-driven recruitment platform that matches job seekers and employers via swipe-style compatibility, then advances hiring through evaluations, messaging, notifications, analytics, and measured outcomes—using a reusable engine architecture with strong boundaries for secure, observable, testable, continuously improving experiences across web and mobile.

# Project Module Description
## Platform engine interaction model (enterprise)
- Defines the official networking protocol for all Platform Engines, covering:
  - Engine dependency rules and strict layer hierarchy (higher layers consume lower layers only)
  - Allowed vs forbidden dependencies between engine domains
  - Communication methods (public APIs, published events, contracts, DI, queues, webhooks, shared interfaces)
  - Engine contracts (purpose, API, events published/consumed, configuration, dependencies, versioning, docs, health, metrics)
  - Synchronous vs asynchronous usage expectations
  - Event architecture requirements (immutable events; required fields including correlation ID, tenant/user IDs, versioning, retry count/metadata)
  - Event lifecycle stages and observability expectations
  - Orchestrators responsibilities (platform, workflow, AI, business capability, journey, platform fabric)
  - Resilience standards (standardized results, error propagation rules, retry strategy limits, circuit breakers, timeouts + fallbacks)
  - Governance standards (semantic versioning, deprecation policy, dependency registry integration, platform validation checks)
- Strategic recommendation included:
  - Platform Dependency Intelligence Engine to detect circular dependencies, architecture drift, coupling issues, and provide consolidation/simplification guidance using registries and engine outputs.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
