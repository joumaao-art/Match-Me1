# Project Summary

MatchMe is an enterprise recruiting platform connecting Job Seekers with employers through job discovery, applications, career profiles, messaging, and recruiting workflows. It supports Job Seeker, Company, and Admin experiences, with English and Arabic localization.

The mobile experience now has a dedicated 11-step Job Seeker onboarding flow, separate from the existing desktop presentation. It supports account-isolated autosave, progress recovery, profile and preference entry, and a completion screen that leads to Discover. Discover uses live job records and account-owned actions for applying, saving, sharing, and swiping.

Credits use a shared account-based backend balance across mobile and desktop. Eligible new Job Seeker accounts receive 20 credits once; existing balances are preserved. Credit deductions and purchase fulfillment use server-side transactional and idempotent handling.

Release readiness is still limited by missing approved legal content, Stripe configuration for purchases, and mobile, Arabic/RTL, and signed-in end-to-end acceptance evidence. Automatic location lookup requires configuration; manual location selection remains available. CV extraction currently supports TXT only.

# Project Module Description

- **Authentication and routing:** Preserves signup, login, verification, role-based routes, and desktop flows. Mobile entry and onboarding use a dedicated route and finite loading/error states.
- **Mobile onboarding:** Uses the semantic steps `PERSONAL_DETAILS`, `GENDER`, `BIRTHDAY`, `CURRENT_LOCATION`, `SKILLS`, `EDUCATION`, `EXPERIENCE`, `PREFERENCES`, `SENIORITY`, `FREE_CREDITS`, and `HOW_IT_WORKS`. Intro and completion screens are separate from the counted steps. Progress is persisted and resumed without relying solely on numeric indexes.
- **Onboarding persistence:** Saves drafts separately from completed steps, validates before marking steps complete, supports retry and recovery, and isolates cached data by account. Back navigation retains saved entries and revalidates dependent fields.
- **Profiles and preferences:** Mobile onboarding shares canonical profile and history records with account editors. Preferences keep roles, keywords, working style, work type, and seniority as distinct signals.
- **Discover and job actions:** Loads real vacancies and persists swipe, apply, save, and share actions to account-owned records. Job actions and credit deductions are server-backed; failed actions can be retried.
- **Credits and subscriptions:** Displays shared account balance and transaction history. Credit awards and deductions are protected against duplicate processing. Purchases require configured Stripe pricing and verified fulfillment.
- **Location and localization:** Manual country and dependent-city selection is available. Consent-based reverse geocoding requires provider configuration. English and Arabic translations are maintained; updated mobile RTL behavior still needs acceptance testing.
- **Company and Admin portals:** Existing portal functionality and desktop presentation are preserved.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Mobile:** Mobile web/app experience; React Native and Expo are also present in the project
- **Backend and data:** Supabase, Node.js, PostgreSQL
- **State management:** React Context API, Zustand
- **Authentication:** Supabase Auth
- **Payments:** Stripe integration with server-side verification; configuration required
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, onboarding contract checks, and database tests

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Run language validation:

   ```bash
   pnpm run check:language
   ```

5. Run mobile onboarding contract checks:

   ```bash
   node scripts/mobile-onboarding-contract.mjs
   ```

6. Run available runtime diagnostics:

   ```bash
   node scripts/runtime-onboarding-isolation.mjs
   node scripts/runtime-seeker-navigation.mjs
   node scripts/runtime-seeker-account-states.mjs
   node scripts/runtime-auth-matrix.mjs
   node scripts/runtime-signup-e2e.mjs
   ```

7. Configure Supabase, database policies, Stripe prices and secrets, and any location provider credentials before testing those integrations. Confirm migrations are applied. Approved legal copy must be supplied before release.
