# Project Summary
MatchMe is an AI-driven recruitment platform that enhances the hiring process for job seekers and employers through a user-friendly web and mobile application. It utilizes intelligent compatibility scoring and a swipe-based interface to increase user engagement. The platform features a mobile app developed with Expo and a web application built using Vite and React, with a backend powered by Supabase and PostgreSQL. Key functionalities include a messaging system, notification center, subscription plans, analytics, and a premium **Candidate Directory** for advanced recruitment capabilities. The **Universal Collections Engine** allows for real-time synchronization and collaborative features across modules, establishing MatchMe as a comprehensive recruitment solution.

# Project Module Description
- **Frontend**: Vite and React interface with role-based routing for job seekers, companies, and administrators.
- **Backend**: Supabase for authentication and data management with a PostgreSQL schema.
- **Mobile App**: Expo and React Native for seamless job discovery and applications.
- **Shared Packages**: TypeScript models, validation schemas, localization, API services, and reusable utilities for web and mobile.
- **Authentication**: Role-based system for secure user management.
- **Internationalization**: Bilingual support (English and Arabic) with RTL and LTR capabilities.
- **Company Dashboard**: Interactive statistics for managing vacancies and applications.
- **Candidate Directory**: Premium feature for evaluating and saving job seekers.
- **Job Seeker Experience**: Enhanced UI for profiles, CVs, and notifications.
- **AI Matching Engine**: Compatibility scoring for job matching.
- **Messaging System**: Controlled messaging based on hiring workflows.
- **Notification Center**: Manages notifications via various channels.
- **Subscription Plans**: Centralized billing engine with multiple tiers and payment integrations.
- **Analytics Dashboard**: Admin portal with KPIs.
- **Role-Based Access Control (RBAC)**: Configurable roles and permissions for management.
- **Super Admin Platform**: Comprehensive management interface for platform administrators.
- **Universal Collections Engine**: A configuration-driven system that supports various collection types and powers features like Talent Collections for managing saved candidates.
- **Engineering Charter**: A foundational document outlining mandatory engineering principles, development rules, and a checklist for architectural reviews.
- **Discover Experience**: Redesigned mobile user interface with a **Two-Level Card Architecture** for optimized decision-making without scrolling.

# File Description Inventory
- **app/backend/README.md**: Documentation for backend setup and configuration.
- **app/frontend/README.md**: Documentation for frontend setup and usage instructions.
- **app/frontend/src/App.tsx**: Main application component managing routes and context.
- **app/frontend/src/lib/ai-matching-engine.ts**: Implementation of the AI matching engine.
- **app/frontend/src/lib/i18n.ts**: i18n configuration for localization, including fallback mechanisms and missing key tracking.
- **app/frontend/src/lib/notification-center.ts**: Notification system managing events.
- **app/frontend/src/lib/performance.ts**: Utilities for performance optimization.
- **app/frontend/src/lib/security.ts**: Security utilities for input validation.
- **app/frontend/src/pages/**: Various application pages including Admin, Analytics, Company, JobSeeker, LearnMore, Messages, Notifications, ResetPassword, and Subscription.
- **app/frontend/src/components/shared/BottomSheet.tsx**: Reusable component for displaying Level 2 content with swipe-to-close functionality.
- **app/frontend/src/components/shared/EnterpriseNavigation.tsx**: Component for enterprise navigation with branding support.
- **app/frontend/src/components/shared/PortalBrand.tsx**: Component for standardized branding across all authenticated portals.
- **app/frontend/src/components/shared/CollectionEngine.tsx**: Universal Collections Engine implementation for managing various collection types.
- **app/frontend/src/components/shared/TalentCollections.tsx**: Implementation of Talent Collections, utilizing the Universal Collections Engine for managing saved candidates.
- **app/frontend/src/components/shared/CollectionEnterprise.tsx**: New UI components for enterprise features including activity tracking, comments, analytics, AI insights, automation, and sharing.
- **app/frontend/src/components/shared/StatCard.tsx**: Component for displaying statistics in various formats.
- **docs/enterprise/Engineering Charter.md**: Foundational document outlining engineering principles, development rules, and architectural review standards.

# Technology Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
