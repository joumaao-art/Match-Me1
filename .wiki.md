# Project Summary

MatchMe is a recruiting marketplace where job seekers discover vacancies, manage applications, and connect with employers, while companies publish roles and review applicants. It provides Job Seeker, Company, and Admin experiences, supports English and Arabic, and uses Supabase to persist marketplace activity.

The mobile Job Seeker Dashboard brings together search, application categories, recent applications and statuses, application details, saved jobs, and skipped-job reconsideration. User-reported manual acceptance passed for these workflows, mobile navigation, and Arabic responsiveness. The current implementation is preserved and ready for the next development phase. Independent validation also passed for TypeScript, 117 automated contracts, lint, production build, and rollback-only Supabase authorization and workflow checks.

VIA Premium offers monthly and yearly plans ($10/month and $100/year), with 17% savings displayed for yearly billing. Payment sandbox readiness is not certified: production paid access still requires complete Stripe webhook configuration and a verified sandbox transaction. Native purchases remain disabled pending approved store billing.

# Project Module Description

- **Authentication and routing:** Signup, login, verification, role-based routes, and shared-job authentication recovery.
- **Mobile onboarding:** Eleven semantic onboarding steps with account-isolated draft recovery, validation, and derived birthday age display.
- **Job Seeker Dashboard:** Mobile navigation, search, application categories, recent applications and statuses, application details, saved-job actions, and skipped-job reconsideration.
- **Vacancy discovery and decisions:** Vacancy discovery and ranking fallback, preference-aware matching, eligibility guidance, and persisted actions with ownership, duplicate, credit, and expiry safeguards.
- **Saved Preferences:** Mobile preferences UI and service for saving and restoring seeker preferences across logout and login.
- **Company marketplace:** Persisted Company profiles, private logo storage, vacancy drafts and publication, dashboard counts, and applicant review.
- **Applications and matches:** Company review decisions update application statuses and seeker matches.
- **VIA Premium and credits:** Credits popup, Monthly and Yearly plan selection, subscription management, and server-derived Premium eligibility. Yearly is the fresh-page default; existing pending checkouts retain their original plan.
- **Payments and entitlements:** Stripe checkout and verification use server-side catalog validation; subscription lifecycle updates require verified webhook signatures.
- **Shared job links:** Stable vacancy IDs support web landing pages and authentication recovery. Android App Links require deployment configuration.
- **Profiles, messaging, and localization:** Shared profile and history records, preference management, existing messaging, English/Arabic translations, and Company/Admin portals. Live chat and unread-count consistency are not established.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Native app:** Expo and React Native, with a shared-screen WebView container
- **Backend and data:** Supabase, Node.js, PostgreSQL
- **Authentication:** Supabase Auth
- **State management:** React Context API, Zustand
- **Payments:** Stripe checkout and webhook integration with server-side verification
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, contract checks, and rollback-only database tests

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Validate translations:

   ```bash
   pnpm run check:language
   ```

5. Run marketplace, Premium, Saved Preferences, Swipe, navigation, Dashboard, and onboarding contracts:

   ```bash
   node scripts/live-marketplace-contract.mjs
   node scripts/via-premium-contract.mjs
   node scripts/savings-preferences-contract.mjs
   node scripts/mobile-swipe-contract.mjs
   node scripts/seeker-navigation-contract.mjs
   node scripts/mobile-dashboard-contract.mjs
   node scripts/mobile-onboarding-contract.mjs
   ```

6. Run available runtime diagnostics:

   ```bash
   node scripts/runtime-onboarding-isolation.mjs
   node scripts/runtime-seeker-navigation.mjs
   node scripts/runtime-seeker-account-states.mjs
   node scripts/runtime-auth-matrix.mjs
   node scripts/runtime-signup-e2e.mjs
   ```

7. Configure Supabase and apply required migrations. Deploy payment functions with the required Stripe secrets. Complete webhook configuration and verify a sandbox transaction before enabling paid access. Android App Links require deployment-specific domain association, package and signing fingerprints, and device/build access. Native purchases remain disabled pending approved store billing.
