# Project Summary

MatchMe is an enterprise recruiting platform that connects job seekers with employers through job discovery, applications, career profiles, messaging, and recruiting workflows. It supports Job Seeker, Company, and Admin experiences, with English and Arabic localization.

The Job Seeker mobile experience includes an 11-step onboarding journey with account-isolated draft recovery, plus a navigation redesign centered on Swipe, Dashboard, and Profile. Dashboard provides shortcuts to Messages, Applications, and Matches; Profile retains existing profile and settings features. Desktop navigation and backend logic are unchanged.

Release readiness still depends on approved legal content, Stripe purchase configuration, and outstanding signed-in mobile acceptance. Current mobile acceptance, including narrow-screen layouts, RTL behavior, and navigation interactions, remains unverified. Existing chat is demo/simulation-backed, so live message and unread-count consistency is not established.

# Project Module Description

- **Authentication and routing:** Signup, login, verification, and role-based routes for Job Seeker, Company, and Admin experiences.
- **Mobile onboarding:** Eleven semantic steps cover personal details, gender, birthday, location, skills, education, experience, preferences, seniority, credits, and product guidance. Drafts are account-isolated; validated completed steps support recovery. Birthday age is derived and not saved.
- **Job Seeker navigation:** Mobile bottom navigation has three tabs: Swipe, Dashboard, and Profile. Navigation state synchronizes with seeker URLs, while legacy Discover links remain supported. Dashboard shortcuts lead to Messages, Applications, and Matches. Profile editing is a distinct section so browser Back can return to the Profile hub.
- **Swipe and job actions:** Displays job opportunities and supports account-owned job actions. Job actions and credit deductions are server-backed.
- **Profiles and preferences:** Profile and history records are shared with account editors. Preferences maintain distinct roles, keywords, working styles, work types, and seniority.
- **Credits and subscriptions:** Displays shared account credit balances and transaction history. Signup grants use duplicate protection; purchases require configured Stripe pricing and verified fulfillment.
- **Messaging:** The Dashboard Messages shortcut displays a badge only when the existing unread API returns a valid count; unknown counts are hidden. Live chat and unread consistency remain unverified.
- **Location and localization:** Manual country and dependent-city selection is available; reverse geocoding requires provider configuration. English and Arabic translations are maintained.
- **Company and Admin portals:** Existing portal functionality and desktop presentation are preserved.

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Mobile:** Mobile web/app experience; React Native and Expo are also present
- **Backend and data:** Supabase, Node.js, PostgreSQL
- **State management:** React Context API, Zustand
- **Authentication:** Supabase Auth
- **Payments:** Stripe integration with server-side verification; configuration required
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, contract checks, and database tests

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Validate translations:

   ```bash
   pnpm run check:language
   ```

5. Run the Job Seeker navigation and mobile onboarding contracts:

   ```bash
   node scripts/seeker-navigation-contract.mjs
   node scripts/mobile-onboarding-contract.mjs
   ```

6. Run available runtime diagnostics:

   ```bash
   node scripts/runtime-onboarding-isolation.mjs
   node scripts/runtime-seeker-navigation.mjs
   node scripts/runtime-seeker-account-states.mjs
   node scripts/runtime-auth-matrix.mjs
   node scripts/runtime-signup-e2e.mjs
   ```

7. Configure Supabase, database policies, Stripe prices and secrets, and any location-provider credentials before testing those integrations. Apply the required migrations and provide approved legal content before release.
