# Project Summary
MatchMe is an enterprise Talent Platform that uses swipe-style compatibility and AI-powered matching to connect job seekers and hiring teams, then drives recruiting through workflows, messaging/notifications, analytics, and measurable hiring outcomes. The platform standardizes architecture via reusable Platform Engines and a reference implementation blueprint so web/mobile experiences stay secure, observable, testable, and governance-ready.

# Project Module Description
## Platform Reference Implementation (Prompt 4C)
Defines the canonical end-to-end enterprise blueprint for how the full platform stack composes and operates, including:
- Complete Platform Stack layering from mobile/web experience through experience engines, workflow engines, business engines, AI engines, security engines, and infrastructure/operations.
- Reference user journeys (job seeker discovery/swipe/apply, company hiring pipeline, recruiter discovery) that describe engine-to-engine responsibilities.
- Core flows and conventions (authentication, notifications, search, AI matching, workflow/activity/audit, event publishing, data flow, AI data flow).
- Engine dependency and directionality rules (dependencies flow downward; no upward coupling).
- Component composition guidance (decision screen and library-driven UI composition).
- Platform registries and governance assets (feature/component/engine/capability/model/prompt/integration/event/security/compliance/trust registries).
- Platform intelligence and dashboards (engineering/operations/security/AI/governance/component/workflow/health/executive views).
- Disaster recovery and deployment references (detect→alert→retry→fallback→recovery→audit; staging/approval/rollback).
- Strategic rule: every new feature/module/engine/capability must reuse approved components/engines/workflows, publish events, update registries, and pass validation/governance; changes requiring new architectural patterns must be reviewed and incorporated into this blueprint.
- Strategic recommendation for a Solution Blueprint Library to catalog reusable reference implementations for common enterprise capabilities.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies (web):
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
