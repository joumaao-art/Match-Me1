# Project Summary
MatchMe is an AI-driven recruitment platform that connects job seekers and employers through swipe-based discovery and compatibility scoring, then helps both sides evaluate, communicate, and track outcomes. The product includes messaging, notifications, analytics, and subscriptions, plus a premium Candidate Directory, with a reusable “engine” approach that keeps scoring and interaction UX consistent across web and mobile under an enterprise security-first backend.

# Project Module Description
- Web Frontend (app/frontend)
  - Role-based portals for Job Seeker, Company, and Admin with routing, shared UI components, and engine-driven interaction patterns.
  - Shared libraries for feature registry, AI matching/scoring logic, score visualization, notifications, and security/validation utilities used by the UI.
  - Internationalization support (LTR/RTL) designed for English and Arabic.
- Mobile App (app/mobile)
  - Expo + React Native app for discovery and swipe-based decisions, aligned with shared interaction standards and shared constants/config.
- Shared Packages (app/frontend/packages/shared)
  - Reusable TypeScript models/validation/i18n/constants/utilities to ensure consistent behavior between web and mobile.
- Enterprise Documentation
  - Governance and standards for engineering and platform consistency via “engines” (architecture/experience charter) and now a centralized UI Design System specification.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
   - Run `npm install` in `app/mobile`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: `pnpm run start` in `app/frontend`
   - Mobile: `expo start` in `app/mobile`
