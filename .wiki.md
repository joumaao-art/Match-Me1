# Project Summary
MatchMe is an AI-driven recruitment platform that helps job seekers and employers discover, evaluate, and match talent via swipe-based interactions and compatibility scoring. The product supports messaging, notifications, analytics, and subscriptions, plus a premium Candidate Directory, all backed by reusable “engines” and an enterprise-ready, security-focused backend to keep decisions, scoring, and UX consistent across web and mobile.

# Project Module Description
- Web Frontend: Vite + React + TypeScript app with role-based routing for Job Seeker, Company, and Admin users.
- Mobile App: Expo + React Native app for discovery and swipe-based decisions.
- Shared Packages: Shared TypeScript models/validation/i18n/constants/utilities used across web and mobile.
- Reusable Platform “Engines” and libraries:
  - Card/Swipe UI engines for consistent evaluation interactions and feedback
  - ScoreVisualizationEngine for standardized AI score/KPI rendering
  - AI Matching Engine for compatibility scoring logic
  - Feature Registry for configuration-driven feature access
  - Shared messaging/notifications/analytics utilities and security helpers
- Internationalization: i18n with English/Arabic and RTL/LTR support.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
   - Run `npm install` in `app/mobile`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Frontend: `pnpm run start` in `app/frontend`
   - Mobile: `expo start` in `app/mobile`
