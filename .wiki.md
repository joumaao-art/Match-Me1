# Project Summary
MatchMe is an AI-driven recruitment platform that matches job seekers and employers using swipe-style compatibility, then drives hiring via evaluations, messaging, notifications, analytics, and tracked outcomes—governed by reusable “engine” patterns across web and mobile to ensure consistent, secure, observable behavior and premium engagement for qualified users.

# Project Module Description
- Platform Engines Specification (Prompt 4)
  - Updated `PlatformEnginesSpecification.md` to add **Part 8 — Security, Compliance & Governance Engines** to complete coverage of the eight-part engine taxonomy (Parts 1–7 already present).
  - Part 8 introduces **13 Security/Compliance Engines**:
    - Identity
    - Access Control
    - Encryption
    - Secrets Management
    - Privacy
    - Compliance
    - Audit Governance
    - Threat Detection
    - Fraud Detection
    - Security Policy
    - Session Management
    - Risk Assessment
    - Governance
  - Part 8 defines platform-level security/compliance expectations: secure, observable, auditable, policy-driven behavior; validation requirements; and an explicit “no bypass” rule reinforced at the platform level.
  - Recommends a **Platform Trust Engine** to compute unified trust scores and inform adaptive security decisions across the ecosystem.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
