# Project Summary
MatchMe is an AI-driven recruitment platform that streamlines the hiring process by connecting job seekers with employers through a responsive web and mobile application. The platform employs intelligent compatibility scoring and a swipe-based interface to enhance user experience for both candidates and companies. It features a mobile app for job seekers developed with Expo and a unified web application built using Vite and React. The backend leverages Supabase, providing a robust PostgreSQL database, role-based access, comprehensive authentication, and a complete company dashboard with extensive management tools. A new matching engine has been integrated to optimize candidate-job matching based on mutual interest.

# Project Module Description
- **Frontend**: Developed with Vite and React, featuring role-based routing for job seekers, companies, and administrators.
- **Backend**: Utilizes Supabase for authentication, database management, and real-time data handling, with a comprehensive PostgreSQL schema.
- **Mobile App**: Built with Expo and React Native, delivering a seamless experience for job seekers to discover and apply for jobs.
- **Shared Packages**: Contains TypeScript models, validation schemas, localization, API services, and reusable utilities for both web and mobile applications.
- **Authentication**: Complete role-based authentication system including sign-up, login, email verification, password recovery, and secure sessions.
- **Internationalization**: Full bilingual support for English and Arabic, including RTL and LTR support, language switcher, and persistence of language preferences.
- **Company Dashboard**: Comprehensive management tools for companies, including profile management, job posting, candidate tracking, analytics, and team management.
- **Job Seeker Experience**: Enhanced user interface for job seekers including Profile, CV, Experience, Education, Certificates, Skills, Languages, Portfolio, Video Introduction, Preferences, Saved Jobs, Applications, Matches, Messages, Notifications, and Settings.
- **Matching Engine**: Implements bidirectional swipe matching, duplicate swipe prevention, swipe history storage, match expiration, undo last swipe, smart ranking with weighted factors, and real-time notifications.

# File Description Inventory
- **app/backend/README.md**: Documentation for backend setup and configuration.
- **app/frontend/README.md**: Documentation for frontend setup and usage instructions.
- **app/frontend/src/App.tsx**: Main application component managing routes and context with complete authentication and role-based access.
- **app/frontend/src/lib/i18n.ts**: i18n configuration for localization, including English and Arabic translations.
- **app/frontend/src/lib/matching-engine.ts**: Implementation of the MatchMe matching engine, including swipe mechanics, smart ranking, and notifications.
- **app/frontend/src/lib/useMatchingEngine.ts**: React hook for managing the matching engine state and actions.
- **app/frontend/src/pages/**: Contains various pages for the application including AdminLogin, Company, Index, JobSeeker, Messages, ResetPassword, and Subscription.
- **app/frontend/packages/shared/**: Contains shared TypeScript types, validation schemas, localization, API services, and utility functions for use across web and mobile apps.
- **app/frontend/packages/shared/src/i18n/ar.ts**: Arabic translation keys.
- **app/frontend/packages/shared/src/i18n/en.ts**: English translation keys.
- **app/frontend/src/pages/JobSeeker.tsx**: Enhanced component for the job seeker experience, integrating various features and sections.

# Technology Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
