# Project Summary
MatchMe is an enterprise recruiting platform that matches job seekers and hiring teams using swipe-style compatibility enhanced by a graph-based career intelligence engine and AI, then completes recruiting end-to-end through governed workflows (messaging/notifications/interviews/pipeline/offer/hire) and measurable analytics.

# Project Module Description
- AI Matching Engine + Career Graph Intelligence Engine: Defines the foundation career graph (users, companies, jobs, skills, education, industries, paths, traits), the real-time matching layer (swipe + reverse matching), explainability, personalization, cold-start handling, performance targets, and matching APIs.
- Governance-aligned platform architecture: Standardizes enterprise API gateway patterns and governed event/webhook/streaming communication, plus canonical entities, data platform and governance, analytics, and security/versioning conventions.
- Messaging, Interviews & Hiring Workflow Engine (Prompt 9): Provides the end-to-end hiring workflow that converts matches into conversations, shortlisting, interviews, decisions, and offers; includes real-time messaging, multi-channel notifications, interview scheduling with calendar integrations, ATS-lite pipeline management, employer collaboration, offer management, analytics tracking, and workflow automation/event publishing.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies (web):
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
