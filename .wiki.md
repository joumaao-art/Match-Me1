# Project Summary
MatchMe is an AI-powered recruitment platform designed to connect job seekers and companies through a responsive web application. Utilizing intelligent compatibility scoring and a swipe-based interface, it aims to streamline the hiring process, making it efficient and user-friendly for both parties.

# Project Module Description
- **Frontend**: Developed using React, featuring a mobile-first design, with components for job browsing, user authentication, and messaging.
- **Backend**: Utilizes Supabase for authentication and database management, ensuring real-time data handling and user management.

# File Description Inventory
- **app/backend/README.md**: Documentation for backend setup and configuration.
- **app/frontend/README.md**: Documentation for frontend setup and usage instructions.
- **app/frontend/src/App.tsx**: Main application component managing routes and context.
- **app/frontend/src/pages/**: Contains various page components for authentication, job seeker and company dashboards, messaging, and subscription management.
- **app/frontend/src/lib/supabase.ts**: Supabase client setup for database interactions.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **Backend**: Supabase, Node.js
- **State Management**: React Context API, TanStack Query
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory.
2. **Build the Project**: Execute `pnpm run build`.
3. **Run the Application**: Use `pnpm run start` to launch the development server.
