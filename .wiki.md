# Project Summary

MatchMe is a bilingual recruiting marketplace connecting job seekers with employers. Job seekers discover vacancies, manage applications, save preferences, and maintain professional profiles; companies publish vacancies and review applicants. Admin tools support marketplace operations.

The Job Seeker experience is available on mobile and desktop. Recent compatibility work improves responsive behavior across mobile web and the existing Expo/React Native shell without rebuilding the application. Android configuration and native-shell error handling were improved; native iOS builds and device tests remain **BLOCKED** and are not claimed as supported or verified.

The Swipe experience includes deterministic, Supabase-backed skill recommendations. VIA Premium offers monthly and yearly plans; paid access depends on complete Stripe webhook configuration and verified sandbox transactions. Native purchases remain disabled pending approved store billing.

# Project Module Description

- **Authentication and routing:** Signup, login, verification, role-based routes, shared-job authentication recovery, and Supabase sign-out.
- **Onboarding:** Mobile and desktop Job Seeker onboarding, validation, account-isolated draft recovery, and confirmed mobile date entry.
- **Job Seeker Dashboard:** Search, application categories and statuses, application details, saved jobs, and skipped-job reconsideration, with mobile and desktop navigation.
- **Swipe and vacancy matching:** Vacancy decisions, preference and eligibility ranking, credits access, and selected-card navigation. Improve My Match provides deterministic skill recommendations, individual skill confirmation, canonical profile saving, and matching-score recalculation.
- **Skill Match analysis:** Authenticated Supabase-backed recommendations with private caching, rate limits, ownership checks, deduplicated saves, and deterministic fallback behavior. No external AI service or API key is used.
- **Responsive mobile experience:** Mobile layouts remain stable when content expands; expanded content is bounded, and bottom navigation provides accessible three-tab navigation.
- **Native app shell:** Expo/React Native WebView container with Android rotation, keyboard resizing, backup, and safe-area configuration. Unconfigured native builds show an error rather than mock job screens.
- **Appearance settings:** Job Seeker Light Mode, Dark Mode, and System Default controls with account-scoped persistence and local caching.
- **Personal profile and skills:** Mobile and desktop editing with shared validation and backend-confirmed saves. Compensation is optional and private.
- **Professional history:** Experience, Education, and Certification editing. Mobile date selections require confirmation; Current/Present options are retained.
- **Saved Preferences:** Mobile and desktop preference interfaces with persistence across logout and login.
- **Profile, account, and resume:** Account overview, private CV access, canonical profile data, and bilingual VIA Resume PDF generation.
- **Logout:** Confirmation-based Supabase sign-out, account-cache cleanup, error handling, and welcome-page redirect. Persisted user data is retained.
- **Support and settings:** FAQ, persisted issue reporting, and Appearance settings. Unconfigured support providers and unavailable account operations are not presented as functional.
- **Company marketplace:** Company profiles, private logo storage, vacancy drafts and publication, dashboard counts, and applicant review.
- **Applications and matches:** Company review decisions update application statuses and seeker matches.
- **VIA Premium and payments:** Monthly and yearly plans, subscription management, credit access, Stripe checkout, server-side catalog validation, and verified webhook entitlement updates.
- **Shared job links:** Stable vacancy IDs support web landing pages and authentication recovery. Android App Links require deployment configuration.
- **Profiles, messaging, and localization:** Shared profile and history records, existing messaging, English and Arabic translations, and Company/Admin portals. Live chat and unread-count consistency are not established.
- **Compatibility readiness:** The readiness report documents the supported architecture, device matrix, functional checks, and limitations. Native iOS development, signed native builds, and authenticated device tests remain blocked. Secure native sessions, push, native OAuth callbacks, file downloads, hinge handling, and store billing require further work.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Native app:** Expo and React Native with a shared-screen WebView container
- **Backend and data:** Supabase, Node.js, PostgreSQL, Supabase Edge Functions
- **Authentication:** Supabase Auth
- **State management:** React Context API, Zustand
- **Skill recommendations:** Deterministic Supabase-backed provider; no external AI integration
- **Payments:** Stripe checkout and webhook integration with server-side verification
- **PDFs and fonts:** Browser PDF generation and Amiri Arabic font asset
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, contract checks, and rollback-only database tests

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Validate translations:

   ```bash
   pnpm run check:language
   ```

5. Run compatibility and Skill Match checks:

   ```bash
   node scripts/mobile-compatibility-contract.mjs
   node scripts/skill-match-contract.mjs
   ```

6. Run other feature checks as needed:

   ```bash
   node scripts/personal-scroll-contract.mjs
   node scripts/mobile-date-confirmation-contract.mjs
   node scripts/seeker-appearance-contract.mjs
   node scripts/mobile-icon-contract.mjs
   node scripts/desktop-parity-contract.mjs
   node scripts/seeker-navigation-contract.mjs
   node scripts/live-marketplace-contract.mjs
   node scripts/via-premium-contract.mjs
   ```

7. Configure Supabase and apply required migrations for profiles, private CV storage, Personal categories, account settings, and Skill Match.

8. Deploy the required Supabase functions. Skill recommendations do not require an external AI service or API key. Configure Stripe secrets and webhook deployment separately, and verify a sandbox transaction before enabling paid access.

9. Compatibility work reports 185 source/unit checks, web lint/build, and a desktop rendering check as passed. A historical appearance regression check remains unresolved. Native iOS development, signed native builds, and authenticated device tests are **BLOCKED**; no native device validation is claimed. Consult the readiness report before native deployment.
