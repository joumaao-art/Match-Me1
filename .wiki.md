# Project Summary

MatchMe is an enterprise recruiting platform that helps job seekers connect with employers through job discovery, swipe-based applications, career tools, and recruiting workflows. It supports job seeker and company accounts, onboarding, messaging, interviews, offers, analytics, and English/Arabic localization.

Job Seeker onboarding now follows a 14-step sequence, ending with an optional app-experience rating. Submitting or skipping the rating completes onboarding and directs the user to Discover. The rating is stored separately from profile and matching data. Account-isolation checks cover saved progress, new accounts, refreshes, completed accounts, and mobile.

# Project Module Description

- **Authentication and routing:** Provides authentication and guarded Job Seeker and Company routes.
- **Job Seeker onboarding:** Uses an ordered step registry for profile setup, preferences, plans, a Discover tutorial, and final app-experience feedback.
- **Onboarding progress:** Resolves progress using semantic step IDs and user-owned state; new users without valid saved progress start at Welcome. Existing legacy progress still requires a planned conversion.
- **App-experience feedback:** Offers a 1–5 star rating, optional written feedback, and a skip option. Feedback is separate from matching and profile settings.
- **Account isolation:** Rejects onboarding state belonging to another user and resets the client store when the signed-in user changes or signs out.
- **Localization:** Supports English and Arabic, including RTL layouts.
- **Engineering checks:** Includes language validation and browser diagnostics for authentication, navigation, signup, and onboarding isolation.

# File Description Inventory

- `app/frontend/src/lib/onboarding-engine.ts`: Defines the ordered onboarding flow and hydrates and persists progress using semantic step IDs.
- `app/frontend/src/pages/JobSeekerOnboarding.tsx`: Renders onboarding steps, including the final optional app-experience rating.
- `app/frontend/src/components/onboarding/OnboardingKit.tsx`: Supplies shared onboarding UI elements.
- `app/frontend/src/App.tsx`: Handles authentication changes and onboarding state reset.
- `app/frontend/packages/shared/src/i18n/en.ts`: English product translations, including rating and tutorial copy.
- `app/frontend/packages/shared/src/i18n/ar.ts`: Arabic translations, including rating, profile review, and tutorial copy.
- `app/frontend/scripts/runtime-onboarding-isolation.mjs`: Checks cross-account isolation and new-user Welcome behavior; the reported account-isolation checks pass 6/6.
- `app/frontend/supabase/migrations/010_app_experience_ratings.sql`: Defines separate storage for app-experience ratings; it has not been applied to or verified against the live database.
- `app/frontend/scripts/check-cjk-engineering-text.mjs`: Checks engineering-controlled files for unintended CJK text.
- `app/frontend/docs/enterprise/*.md`: Enterprise architecture, governance, workflow, and language-policy documentation.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Mobile:** React Native, Expo
- **Backend and data:** Supabase, Node.js, PostgreSQL
- **State management:** React Context API, Zustand
- **Authentication:** Supabase Auth, including email, OAuth, and phone OTP
- **Internationalization:** i18next, English and Arabic/RTL
- **Workspace:** pnpm monorepo
- **Validation:** TypeScript, ESLint, production builds, browser diagnostics, and language scanning

# Usage

1. Install frontend dependencies:

   ```bash
   cd app/frontend
   pnpm install
   ```

2. Start the frontend:

   ```bash
   pnpm run start
   ```

3. Build the production frontend:

   ```bash
   pnpm run build
   ```

4. Start the mobile application:

   ```bash
   cd app/mobile
   expo start
   ```

5. Run language validation:

   ```bash
   cd app/frontend
   pnpm run check:language
   ```

6. Run onboarding isolation and Job Seeker diagnostics:

   ```bash
   cd app/frontend
   node scripts/runtime-onboarding-isolation.mjs
   node scripts/runtime-seeker-navigation.mjs
   node scripts/runtime-seeker-account-states.mjs
   ```

7. Run authentication and signup diagnostics:

   ```bash
   cd app/frontend
   node scripts/runtime-auth-matrix.mjs
   node scripts/runtime-signup-e2e.mjs
   ```

8. Configure Supabase providers, email confirmation, redirects, session persistence, database policies, and required environment variables before provider-specific testing. Apply and verify the rating migration before relying on persistent feedback storage.
