# Project Summary
MatchMe is an AI-driven recruitment platform that creates swipe-style compatibility between job seekers and employers, then drives hiring through evaluations, messaging, notifications, analytics, and tracked outcomes—governed by a reusable engine architecture spanning web/mobile to ensure secure, observable, measurable, continuously improved experiences for qualified users.

# Project Module Description
- Platform Engines Specification
  - Defines the full platform “engine” taxonomy across architecture, foundation, experience, workflow, business, AI, infrastructure/data, security/compliance/governance, and operations/quality.
  - Adds Part 9: Operations, Quality & Platform Governance Engines, which standardize continuous testing, validation, release control, monitoring/observability, incident handling, governance enforcement, technical-debt management, and reliability practices.
  - Establishes Platform Quality Gates (mandatory validations before release) and dashboard/scorecard expectations for measurable continuous improvement.
  - Recommends a Platform Intelligence Engine (“Chief Architect”) to analyze the ecosystem using registries and engine outputs, detect drift/duplication/gaps, and recommend prioritized improvements.

# Technology Stack
- Frontend: Vite, React, TypeScript, Tailwind CSS
- Mobile: React Native, Expo
- Backend: Supabase, Node.js, PostgreSQL
- State Management: React Context API, Zustand
- Internationalization: i18next

# Usage
1. Install dependencies:
   - Run `pnpm install` in `app/frontend`
2. Build the web app:
   - Run `pnpm run build` in `app/frontend`
3. Run:
   - Web: Run `pnpm run start` in `app/frontend`
   - Mobile: Run `expo start` in `app/mobile`
