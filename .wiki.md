# Project Summary
MatchMe is an AI-driven recruitment platform that connects job seekers with companies through a responsive web and mobile application. It enhances the hiring process using intelligent compatibility scoring and a swipe-based interface, ensuring efficiency and user-friendliness for both job seekers and employers. The platform features a fully integrated mobile app built with React Native, a web admin portal for managing company accounts, and a comprehensive backend powered by Supabase. MatchMe has implemented a robust PostgreSQL database schema, complete with role-based access for job seekers, companies, and administrators, as well as a comprehensive authentication system.

# Project Module Description
- **Frontend**: Developed using React and TypeScript, featuring a mobile-first design with components for job browsing, user authentication, and messaging.
- **Backend**: Utilizes Supabase for authentication, database management, and real-time data handling, now with a comprehensive PostgreSQL schema.
- **Mobile App**: Built with React Native, providing a seamless experience for job seekers to discover and apply for jobs.
- **Admin Portal**: A Next.js-based portal for companies and administrators to manage job postings and candidates.
- **Authentication**: Complete authentication system with role-based access, including sign up, login, email verification, password recovery, and secure sessions.

# File Description Inventory
- **app/backend/README.md**: Documentation for backend setup and configuration.
- **app/frontend/README.md**: Documentation for frontend setup and usage instructions.
- **app/frontend/src/App.tsx**: Main application component managing routes and context with complete authentication and role-based access.
- **app/frontend/src/pages/**: Contains various page components for authentication, job seeker and company dashboards, messaging, and subscription management.
- **app/frontend/src/lib/supabase.ts**: Supabase client setup for database interactions.
- **app/frontend/src/services/**: Contains service classes for API interactions, including authentication, messaging, job management, subscription handling, and user profiles.
- **app/mobile/src/App.tsx**: Root component for the mobile application, managing navigation and authentication state.
- **app/mobile/src/navigation/AppNavigator.tsx**: Main navigation setup for the mobile app, including role-based routing.
- **app/mobile/src/screens/**: Contains screen components for various functionalities in the mobile app (auth, job discovery, messaging, etc.).
- **app/mobile/src/stores/**: Zustand-based global state management for authentication and app settings.
- **app/mobile/src/theme/**: Theme management for the mobile app, including colors and spacing constants.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
