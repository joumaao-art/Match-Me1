# Project Summary
MatchMe is an AI-driven recruitment platform designed to streamline the hiring process by connecting job seekers with companies through a responsive web and mobile application. It employs intelligent compatibility scoring and a swipe-based interface to enhance user experience for both job seekers and employers. The platform features a separate mobile application for job seekers built with Expo and a unified web application using Vite and React. The backend is powered by Supabase, which supports a robust PostgreSQL database schema, role-based access, and a comprehensive authentication system.

# Project Module Description
- **Frontend**: Developed using Vite and React, featuring role-based routing for job seekers, companies, and administrators.
- **Backend**: Utilizes Supabase for authentication, database management, and real-time data handling, with a comprehensive PostgreSQL schema.
- **Mobile App**: Built with Expo and React Native, providing a seamless experience for job seekers to discover and apply for jobs.
- **Shared Packages**: Contains TypeScript models, validation schemas, localization, API services, and reusable utilities for both web and mobile applications.
- **Authentication**: Complete role-based authentication system with features such as sign up, login, email verification, password recovery, and secure sessions.

# File Description Inventory
- **app/backend/README.md**: Documentation for backend setup and configuration.
- **app/frontend/README.md**: Documentation for frontend setup and usage instructions.
- **app/frontend/src/App.tsx**: Main application component managing routes and context with complete authentication and role-based access.
- **app/frontend/src/lib/i18n.ts**: i18n configuration for localization using translations from shared packages.
- **app/frontend/src/types/index.ts**: Shared type definitions for the MatchMe platform, re-exporting types from the shared package.
- **app/frontend/packages/shared/**: Contains shared TypeScript types, validation schemas, localization, API services, and utility functions for use across web and mobile apps.

# Technology Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
