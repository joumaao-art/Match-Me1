# Project Summary
MatchMe is an AI-driven recruitment platform that simplifies the hiring process by connecting job seekers and employers through a responsive web and mobile application. It utilizes intelligent compatibility scoring and a swipe-based interface to enhance user experience. The platform includes a mobile app for job seekers developed with Expo and a unified web application built using Vite and React. The backend is powered by Supabase, offering a robust PostgreSQL database, role-based access, and a detailed company dashboard. The integrated AI-powered matching engine optimizes candidate-job matching through embeddings and semantic similarity, providing explainable recommendations and adaptive learning. Additionally, it features a messaging system for user communication, a notification center, and multiple subscription plans with integrated payment options. Recently, a comprehensive Super Admin portal has been introduced for enhanced management capabilities.

# Project Module Description
- **Frontend**: Built with Vite and React, featuring role-based routing for job seekers, companies, and administrators.
- **Backend**: Utilizes Supabase for authentication, database management, and real-time data handling, with a comprehensive PostgreSQL schema.
- **Mobile App**: Developed using Expo and React Native, providing a seamless experience for job seekers to discover and apply for jobs.
- **Shared Packages**: Contains TypeScript models, validation schemas, localization, API services, and reusable utilities for both web and mobile applications.
- **Authentication**: Role-based authentication system including sign-up, login, email verification, password recovery, and secure sessions.
- **Internationalization**: Full bilingual support for English and Arabic, including RTL and LTR support, language switcher, and persistence of language preferences.
- **Company Dashboard**: Management tools for companies, including profile management, job posting, candidate tracking, analytics, and team management.
- **Job Seeker Experience**: Enhanced UI for job seekers with features like Profile, CV, Experience, Education, Certificates, Skills, Languages, Portfolio, Video Introduction, Preferences, Saved Jobs, Applications, Matches, Messages, Notifications, and Settings.
- **AI-Powered Matching Engine**: Implements embeddings and semantic similarity for compatibility scoring based on various factors, delivering compatibility scores and explanations.
- **Messaging System**: Real-time messaging with features like read receipts, typing indicators, file sharing, and conversation archiving.
- **Notification Center**: Comprehensive notification system managing channels for Email, Push, In-app, and SMS, supporting various events and user preferences.
- **Subscription Plans**: Features multiple tiers (Starter, Professional, Business, Enterprise) with integrated payment support (Stripe, Moyasar, Apple Pay, Google Pay).
- **Super Admin Portal**: A comprehensive management dashboard for admins, including sections for Dashboard, Users, Companies, Jobs, Matches, Subscriptions, Payments, Support, Analytics, Content, Reports, Announcements, Feature Flags, Audit Logs, and System Settings.

# File Description Inventory
- **app/backend/README.md**: Documentation for backend setup and configuration.
- **app/frontend/README.md**: Documentation for frontend setup and usage instructions.
- **app/frontend/src/App.tsx**: Main application component managing routes and context with complete authentication and role-based access.
- **app/frontend/src/lib/ai-matching-engine.ts**: Implementation of the AI-powered matching engine, including scoring mechanisms and explainability.
- **app/frontend/src/lib/i18n.ts**: i18n configuration for localization, including English and Arabic translations.
- **app/frontend/src/lib/matching-engine.ts**: Legacy matching engine implementation.
- **app/frontend/src/lib/notification-center.ts**: Notification system managing channels, events, and user preferences.
- **app/frontend/src/lib/useAIMatching.ts**: React hook for managing interactions with the AI matching engine.
- **app/frontend/src/pages/**: Contains various pages for the application including AdminLogin, Admin, Company, Index, JobSeeker, Messages, Notifications, ResetPassword, and Subscription.
- **app/frontend/packages/shared/**: Shared TypeScript types, validation schemas, localization, API services, and utility functions for both web and mobile apps.
- **app/frontend/packages/shared/src/i18n/ar.ts**: Arabic translation keys.
- **app/frontend/packages/shared/src/i18n/en.ts**: English translation keys.
- **app/frontend/src/pages/Subscription.tsx**: New subscription plans page with features including plan selection, usage tracking, billing information, and payment methods.
- **app/frontend/src/services/api-client.ts**: API client for interacting with Supabase, handling authentication and data requests.

# Technology Stack
- **Frontend**: Vite, React, TypeScript, Tailwind CSS
- **Mobile**: React Native, Expo
- **Backend**: Supabase, Node.js, PostgreSQL
- **State Management**: React Context API, Zustand
- **Internationalization**: i18next

# Usage
1. **Install Dependencies**: Run `pnpm install` in the frontend directory and `npm install` in the mobile directory.
2. **Build the Project**: Execute `pnpm run build` in the frontend directory.
3. **Run the Application**: Use `pnpm run start` for the frontend and `expo start` for the mobile application.
